#  孤 味

![](https://mmbiz.qpic.cn/mmbiz_png/E8dLbmPckyJGAIUGa5nJctIhiaVQkDuiboUibpP59s3j1kS6MNrLNEGEhAmIiaooC2E8GtBRhnS46nx5XUhoh2NMuw/640?wx_fmt=png&wxfrom=5&wx_lazy=1&wx_co=1)

hi，我是本期的票根设计小鱼。

“孤味”是台湾方言，意思是一个餐厅只卖一种食物，也形容对人对事的专注态度。

这是我比较喜欢的一部女性群像作品，不仅是有谢盈萱孙淑芳张钧甯几大女神的加持，也是因为它再一次印证了我以为的事：

人类无法逃避一些情感。

![](https://mmbiz.qpic.cn/mmbiz_png/E8dLbmPckyJ9FV9jKKDsyuiaZTMDYtYw3vZNKZUFU8NwHbVNzcYrWoy9dAFuic6wliav3p9Eyc2EynFTu7AV4u5fA/640?wx_fmt=png)

下定决心放弃的话当然会拥抱新生活啊，不再去想的话搞不好会有更好的遇见呢，这种人有什么值得去想去留恋的……

阿嬷就是这样在自己的心甘情愿里孤独又倔强地走完了自己的一生，这个像傻瓜一样的人，会咂摸一下“我才不要这样”和“还好不是我”的人，辛苦了一辈子也没在离婚协议书上签字的人，终于在生命的尽头，释怀了。

人真的可以一辈子恋爱脑啊，真是“越想饮完越走位”。

![](https://mmbiz.qpic.cn/mmbiz_png/E8dLbmPckyJ9FV9jKKDsyuiaZTMDYtYw3mHjTLbsntDvkUM8e0Dmhcccniakw1icms1BMdxvBBvPykgTUPiaicooicXw/640?wx_fmt=png)

所以看完我也有一种“释怀”的感觉，大概是尊重任何人成为任何人吧，忍不住想要说话的人就大胆去聊天吧，忘不了的人就主动告诉他吧，像烂牙一样的人就勇敢拔掉吧，所以背景选了这三姐妹，自由自在的人，专注自己的人，温柔有力的人。

文案选了电影里用洗脸的那一幕“月亮的月光照应着水，用这个水洗脸的人，可以跟月亮一样漂亮哦”。

可能我们都有与生俱来的孤味底色。

开心就好，尽兴就好，和月亮一样漂亮就好。
