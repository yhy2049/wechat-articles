#  《回归》票根

![](https://mmbiz.qpic.cn/mmbiz_jpg/E8dLbmPckyJOWaSt75wichsAFbKQ9VXRFvVBc62hjCs3Lwa2ibrUAKeaor20cwuhhbQHKFXmKXqxJDlHjKLzjJ5w/640?wx_fmt=jpeg)

24帧观影团的朋友们，大家好，我是设计师影靈。

很意外收到无声邀请，设计《回归》这部金狮奖电影的票根。

深夜看完电影后我的感觉就是两个字：战栗。

电影拍的隐忍而克制，但是一些镜头的美却是呼之欲出，让我在看的时候就已经想到了要把这里的画面截图，那个镜头用作设计素材。

票根背面是个人最喜欢的一个镜头，单纯因为美。兄弟二人恐惧而坚定地拖拽着坠亡父亲的尸体，近处的草地幽暗不明，远处的海上朝霞绚丽。

对称构图的那句话是俄语的“好的，爸爸”，也是片中父亲最想从两个儿子口中听到的。从未涉足俄罗斯艺术相关的我也试着用猩红着色的手写体来传达这一绝美画面的悲惨底色。

票根正面是开头躺在床上的父亲和片尾躺在船上的父亲的形象叠化。

床上的父亲在外奔波打拼，回归后睡得深沉像个孩子；船上的父亲在岛上为子坠亡，离开后梦得安详，像是宗教神话里的人物。而一开始听到妈妈说父亲在睡觉，兄弟二人也是从圣经的夹缝中找到的那张父亲的照片，导演安德烈的精妙设计和剧作功底可见一斑。因此，这里我用了类油画效果处理并模糊了图画四周。

原本是打算把死后船上的父亲做成一副挂在床头上的油画。但是这样就显得太泾渭分明，刻意为之了。

电影，还是要朦胧一点好。

很遗憾不能和大家一同线下讨论我的感受。

希望大家喜欢我的设计。
