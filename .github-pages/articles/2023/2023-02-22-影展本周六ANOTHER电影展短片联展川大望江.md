#  「影展」本周六 ·《ANOTHER电影展--短片联展》· 川大望江

**ANOTHER电影展**

ANOTHER国际电影展(ANOTHER Film
Festival)由百代影业有限公司承办，携手北京影视版权文化艺术联合会共同发起，ANOTHER中文译为“另外”，另一种故事、另一种态度，我们希望以类型化眼光去发掘青年电影创作者，旨在为更多的类型电影导演搭建资源共享平台，为影视机构推荐优秀人才及作品，推动影视教育的行业化发展。影展每季度固定举办“展映单元”、“竞赛单元”，每年将举办线下展映，未来另会根据实际情况增设“青年电影训练营”等新兴活动形式。

目前，ANOTHER组织的线下影展传播量已超过20000人次，作为中国新兴青年电影展，我们愿随青年电影人一起茁壮发展，推动青年创作者的商业成长。
