#  「放映」本周日 ·《廊桥遗梦》· 大源

**写在前面**  
当个人在家庭中被消减，一个意大利女人性格中的两面。梅尔斯特里普与克林特伊斯特伍德精彩绝伦的表演，让廊桥的梦坠入每一位观众的心田。  
不在沉默中爆发，亦有可能在沉默中告别。中年人的心动，始于一潭死水，止于相顾无言。  这样的一段经历于你我而言有何意义？情深不寿，一石激起万千漪涟。

**放映员说**  
选择本身是一种基于已知试图去驾驭未知。  
可在婚姻与家庭的洋流中飘荡，他的出现也绝非是一个静悄悄的港湾。投入他的怀抱，看似是一种归宿与回归。实则这位汹涌的浪子会给这艘船无尽的波动与休止。  
她的一部分永远停留在了家庭的过去，像是船在港湾再也不出海远航；她的另一部分仍然脆弱敏感，每一次来自内心的海水拍打，都会让她回想曾经多一点。这是一个无解的命题、是荒谬的港湾、是变幻莫测的海洋、是那个动人心魄却又永远一成不变的午后春梦。  
我只是很高兴她做选择前、抉择时以及选择后所展现的自由意志。激动之情甚至溢于楚门说出那句祝安的临別之言，走出那扇门。  
写到这里，《爱在黎明》里杰西的那番时空穿越旅程的言论不由再次从脑海浮现。“问题就是，我们都不会早知道。”  
那么远的法国，那么多的酒馆，那么大爱荷华，乡村路旁的一户户人家，可他偏偏带走了我，而我又无悔地留下了他。  
电影的结局是那么得美国，不止于“只是当时已惘然”的意蕴绵长，更求得“且将新火试新茶”的焕发新春。  
不管是金苹果还是银苹果，自此之后，日月当空，同照你我。
