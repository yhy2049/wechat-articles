#  「嘉宾映后」本周六 ·《完美的世界》· 渡口

**写在前面**  
这部影片最大的特别之处，在于把一个犯罪逃亡的故事转换成了家庭度假。《完美的世界》是一部堪称教科书级别的公路电影。  
“这是一辆偷来的时光飞船，哦不，只是暂时借用。加速，是通往未来，减速，是回到过去。当你停下来的时候，你需要享受现在的生活，我们是穿越德州的时光旅行者！”  
毫无疑问这绝对是枚重磅催泪弹，公路片的基调，一些伴我同行的影子，故事其实相当简单，但是没有被本身的俗套剧情影响。
