#  「侯麦系列」本周六 ·《春天的故事》· 世纪城

**写在前面**  
“一年一度，转瞬即逝。  教人依依不舍的季节，我还能在人世间与它相逢几回？  也许清算剩余的次数，才最能让我们痛感人生的短暂。  ”  
看候麦的电影，故事情节从来不是重点。桌子上的台灯、随手拿起的书，女主脖子上的蓝色项链、鲜花、钢琴曲，每一处都能吸引我的注意力。他拍的是平淡生活中的极致美学。法国有深厚的人文教育底蕴，他们在饭桌上聊起哲学像在聊八卦一样，在郊外花园的躺椅上读书，消磨时间。  
一年四季，翻来覆去都是那些无聊的故事，情情爱爱，猜忌怀疑。唯独是对生活的疏离感和无条件热爱，令他们永远充满魅力。这是一部能让你想要好好生活的电影。

**放映员说**  
春天刚到来的时候，骤冷骤暖的气候让我们踟蹰不前，关于生命的一切都还在试探。  
在前两次《冬天的故事》和《夏天的故事》的放映中，我们感受到两种不同的秩序：冬天是寒冬中的坚守，夏天是沙滩上的多情。介乎其间的《春天的故事》，则在秩序感和占有欲之间拉扯。一种是渴望同他人建立亲密关系，一种是隔在人与人之间的边界，渴望亲密关系演化出来的占有欲和拒绝打破人与人之间的秩序，形成了一种荒谬感。  
侯麦把这种荒谬放在春天的情境之中，介于冷暖之间的不确定气候，马蒂斯的《小鹦鹉与美人鱼》、舒曼的《黎明之歌》、贝多芬、康德、维特根斯坦等元素都镶嵌在其中。  
侯麦说：“我不解释，我只展现”。春天中的人物，她们的思想、行为，无不深受知识和艺术的影响。每个人物都在通过语言诠释自身，为自己注解，从而表露出自己真实的一面。透过古典的学问和艺术，我们可以代入故事中的任何一方，进入拥有秩序或是占有欲的一方。  
感知这种荒谬，得到自己的答案。
