#  「新片专场」本周三 ·《宇宙探索编辑部》· CGV

**写在前面**  
《宇宙探索编辑部》豆瓣开分8.7，横扫第五届平遥国际电影节，拿下费穆荣誉最佳影片等。在之后的BIFF北影节展映，更是一秒售罄，令影迷翘首以待！  
这无疑是中国科幻电影的创新形式，4年的剧本打磨，节奏丝滑顺畅，故事足够动人。古早走进科学的即视感，伪纪录片的风格，讲述了一个浪漫又荒诞的故事。  
![](https://mmbiz.qpic.cn/mmbiz_jpg/E8dLbmPckyJrGjuXNSo1QhUUZb6ZfKlQ641ibwumlrYdGVBmSsn4iaJGiaJVkKPa83PKtAJpFTcVdINl05LOcdRcw/640?wx_fmt=jpeg)  
**放映员说**  
在国产片中很少做到的是，它呈现了个人与世界的相遇。探讨“人存在于世”这样的概念，但用了边缘的角色和荒谬的行为，消解了那份说教和严肃。  
它不是一张只能写字画画供人阅读的白纸，而是一扇透明的窗，可以透过它望向一个世界。  
现实中，人对生活不满，才会怀念过去、寄望未来。  电影里，人对自身不解，于是仰望宇宙，追寻答案。  
最终电影与现实合二为一，宇宙就是过去和未来，但答案存在于你心间。从怪人怪事，回归到“人心即世界”这个大命题。  
难得的是，整部片子在喜感、神秘、悲伤几种氛围之间切换着，没有割裂。也挺喜欢里面摇摇晃晃的镜头，一切都是偶发，没有循规蹈矩，人物对未知世界的追寻就这么跌跌撞撞。
