# 24FRAMES PROJECT

在豆瓣/哔哩哔哩等网站上，昆汀一直是关注度和讨论度非常高的一位导演。但现实生活中，身边却少有发现昆汀的影迷。  

那些网络遇到的“昆迷”中，有真的恋脚癖；有确实的“MF侠”；当然，也有一般无二的影迷——借用昆汀的话说着“这TMD只是一部该死的电影而已！”  

这让人愈发好奇，这些网络上持续活跃着的“昆迷”们，在现实中会是怎样的呢？喜欢昆汀的你，是什么样的呢？  

昆汀曾说，他这一生只拍10部电影。在他导演生涯的最后一部作品《影评人》（The Movie Critic）到来之前，今年恰逢他的60岁生日。
借此机会，24帧观影团开启昆汀系列专场，于5月正式启动，计划放映8场，让我们一起走进这位鬼才导演的电影世界！  

奇妙的昆汀电影之旅即将开始，长按扫码，持续关注！
