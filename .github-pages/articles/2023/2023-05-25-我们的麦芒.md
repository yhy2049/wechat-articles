#  「我们的麦芒」

**写在前面**  
麦芒圆桌放映将在本周开启。  说起“麦芒”，取自“针尖对麦芒”。  

人与人之间的关系非常微妙。如果只相遇一次，那么人们的对话多少会有所保留，留有余地。  
而我们希望在电影放映后的讨论是“带着冲突的”，能打破各自的界限，让关于电影的言论有生长的空间。  
于是，我们集合了几位志同道合的伙伴一起选出8部电影，一起观影，一起针锋相对。  
在半年前，我们在做侯麦“人间四季”四部曲系列放映活动时，慢慢埋下了麦芒的种子。四部曲的放映并不匆忙。四部电影陪伴我们走过冬天，迎接春天，我们也逐渐和大家变得熟络起来。除了侯麦，我们在映后还会聊到法国电影新浪潮、其他流派的欧洲电影、华语电影，甚至日本文学。  
无论是电影、音乐还是文学，都是艺术的一隅，而艺术又是生活的一隅。能用这些“文艺的东西”以小见大，让电影走进生活，或许只需要一群人，一个圆桌，一次交流。  
在麦芒圆桌，我们用电影去触摸未知，去探索内心的表达。总有一部电影会让我们相遇。  
有幸的话，希望麦芒圆桌对我们来说是一段令人享受的旅程。
