#  「影展」浪影像×24帧 · 冥王星时刻

**写在前面**  
![](https://mmbiz.qpic.cn/mmbiz_jpg/E8dLbmPckyI0mzq28aU1DZxnriasWV96ibXVOoXJQ7Cp7xxPgJLAiaDLLnC9QiaTErTVQKjwtIibEJiblGdE3kMMW6Vw/640?wx_fmt=jpeg)  
冥王星时刻，是占星学中的一个重要概念，也是电影史上的一个关键词。电影作为一种社会和文化的历史见证，不仅反映了时代的变迁，也影响了社会的变革。  
在每一个冥王星时刻，电影都扮演了不同的角色，或者是挑战权威和传统，或者是宣扬理想和信念，或者是探索自我和真相，或者是创造美好和幻想。  
本次电影展旨在通过不同类型、不同风格、不同主题的电影作品，展现我们如何面对这个变化的时代的挑战，如何用影像语言表达我们对冥王星时刻的理解和感受。这些电影作品或许会让你震撼、惊悚、感动、启发，或许会让你思考、质疑、反抗、超越。  
无论如何，我们希望你能从这些电影作品中找到自己与冥王星时刻相连的那一点火花，并用它点燃自己内心深处的那一团火焰。
