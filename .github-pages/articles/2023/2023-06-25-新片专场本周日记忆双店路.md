#  「新片专场」本周日 ·《记忆》· 双店路

**写在前面**  
阿彼察邦：“当我看侯孝贤、杨德昌或蔡明亮等台湾电影时，我总是会睡着。多年后，我的电影也让观众睡着。我想这样的电影有种特别力量，能将观众转移到不同的世界，一个不同的放松状态。在那里，我们可以暂时放下自己；电影引渡我们到梦的世界，苏醒之后，我们仍然在那里。”  
![](https://mmbiz.qpic.cn/mmbiz_jpg/E8dLbmPckyJeuuxEKdsic4KgeJOZCf70ASFUHSIczuTRG53Dt3EuyT55zOgLia9mibpjWWVpwibAXvUtwCc81VCyQQ/640?wx_fmt=jpeg)  
**放映员说**  
声音是感知终端的方式，而记忆的连接才是传导介质本身，借着声音的作用，历史与文化都坠入无边的孔洞之中。  
阿彼察邦的电影是如同以太一样的存在，在时间与空间的缝隙中徘徊，构建起世界的连接。他博大的，将艺术的虚空与空间的虚无两者包含在其中，声音是存在的，探索对象却是虚无的、不可捉摸的。蒂尔达斯文顿对着艺术馆的玻璃，正是对虚空的凝视。  
如尼采指出存在的非逻辑性，《记忆》亦是非逻辑的，他指出了历史的价值，同时也指出了历史与空间之间的非逻辑自然关联，在解构、打破之后并非是重建逻辑秩序，而是让一切归于混沌，归于安然，这也正是阿彼察邦的独到之处。
