#  「放映」本周六日 ·《关于我和鬼变成家人的那件事》

**写在前面**  
2023年初，《关于我和鬼变成家人的那件事》这部电影的预告片刷遍各大媒体平台，而它的题材也诠释了为什么这么高的关注度：喜剧、悬疑、灵异、同性。  
故事讲述恐同的直男警察吴明翰无意捡到一个红包，竟阴差阳错与同性恋鬼魂毛毛结了冥婚。而工作上棘手的案子，让吴明翰不得不联手他的鬼魂老公一同追凶。  
电影笑点密集，泪点也很恰当，喜剧鬼片的题材让人联想到早年的经典港片，而LGBT元素的加入又让该题材变得新颖无比。  
电影看似塑造了许多刻板印象的形象，但也是一个撕去标签的过程，也在LGBT议题外探讨了女性议题。

**放映员说**  
你们好像在拍一种很新的鬼片诶。  
最初关注到这部电影是在微博上看见博主发布的宣传片，又好笑又好怕。许光汉这张脸在当年《想见你》的时候不知道捕获了多少人的少女心，这一次出演也是让人眼前一亮。  
顺带一提的是，本片的女主塑造也很不错，一般情况下此类题材的影片里，女性角色往往是被淡化甚至被当做工具人。但女主这个角色意外的非常出彩，让人印象深刻。  
说点正经的，“都什么时代了，还恐同？”这句话其实有点刺痛人的。台湾作为全亚洲第一个支持同性恋婚姻合法的地区，当年街上庆祝的年轻人们的照片还历历在目。  
看到这里的时候有一种感觉，好像这句话是在对时代呐喊，同性恋死后变成鬼魂也只是更不完整。很喜欢这种故事，虽然不免俗套，但却俗套得很舒服，像把人包裹起来一样。同志们自我认同，恐同人反而变成少数人。  
刷豆瓣的时候看见一条短评：对岸真是春风化雨。确实是一部诚意满满又十分不错闪着光的台湾电影，恼羞成怒都是台湾式的娇嗔，可爱得不行。  
“想捡你只想捡你”  
多可爱啊。
