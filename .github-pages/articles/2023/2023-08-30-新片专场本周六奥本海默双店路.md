#  「新片专场」本周六 ·《奥本海默》· 双店路

**写在前面**  
“实拍狂魔”诺兰当年拍《星际穿越》愣是种了一片玉米地，而《奥本海默》竟然连核爆场景都不用特效，据透露是用了相当接近的炸弹，以及为了还原实验室直接现建了小镇。  
《奥本海默》全片通通使用胶片拍摄，不仅如此，诺兰想要的70mm大画幅黑白胶片在整个影史上都没有出现过，可以说为了这部电影，诞生了一款imax画幅的黑白胶片。  
![](https://mmbiz.qpic.cn/mmbiz_jpg/E8dLbmPckyI7iaCENoKQMNkPpRCRGRtArbEKGCib7keOcvfoLeGNswWdW0ThicR9CDXI3xvZ1xGxRicHMn802gyAPA/640?wx_fmt=jpeg)  
**放映员说**  
该片是继《敦克尔克》后诺兰再次尝试的真实历史背景电影，而一如《敦克尔克》那样《奥本海默》也不会温和地娓娓道来，上来就是中场，时间线来回交错。  
彩色和黑白：像《记忆碎片》一样，片中用彩色和黑白做了区分，彩色代表奥本海默的主观视角，黑色代表了围绕他发生的真实事件。“人类诞生于世，先哭喊后歌唱”本片的音乐充斥着浪漫奔放，对大自然和生命的歌颂，对宇宙奥秘的敬畏。音乐在《奥本海默》中并非锦上添花而是不可或缺的元素。要知道影片九成都是对白，长时间的对白会让观众产生疲倦，而配乐则成为了人与人共通的语言，与宇宙对话。  
讲到最后，不得不说一下诺兰一贯对电影的态度，他不给出答案而是将人类的命运答案留给观众思考。原子弹的诞生是必然也是开始，人类生命的延续中是否又会激进地  赌
上一切爆发战争然后同归于尽？  诺兰以悲剧式的发问留给我们无尽的思考空间。
