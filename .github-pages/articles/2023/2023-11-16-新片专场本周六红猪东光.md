#  「新片专场」本周六 ·《红猪》· 东光

**写在前面**  
这是一个关于成年人梦想和现实，以及关于爱的童话故事原本是王牌飞行员，却被“施了魔法”变成猪依然有着人类的思想，却有了截然不同的视角于是脱离了原有的“体制”，自我放逐成为边缘却有了更加自由的意志以及更广阔的视野这一切，都让一这部《红猪》稍显异类在宫崎骏以少女少年为主的青春作品中非常独特。  
![](https://mmbiz.qpic.cn/mmbiz_jpg/E8dLbmPckyJ8Io0AKm2ZwT180CtlewPX2Tz6enN97EDYaiazG4sb5uGOQwOC93BsS8v02szM0ID1jPcLta9cUOw/640?wx_fmt=jpeg&from=appmsg)  
**放映员说**  
战争的本质就是将人异化，同时将对手“非人”化，这样才能获得更高效、更残暴、更有利的战争机器，所以宫崎骏无疑用魔法做了一个反讽非常有趣的点，相信也是他创作的初衷
反战是他一贯的主题，而这部格外有趣优美的复古风格、时而细腻丰富、时而大气的场景有些old school的人物塑造，都让这部“动画片”更适合成人观看。  
片中的女性角色可是丝毫没有时代局限一如既往地坚强而独立，有自己的品位和思想同时还兼具率性与温柔如果说之前那些宫崎骏相对更为出名的作品重映
还出于一些怀旧情结的话那这部《红猪》能在上映31年后登上中国大陆的大银幕确实非常意外。这也是继《天空之城》《龙猫》《千与千寻》《崖上的波妞》后吉卜力电影第五次在国内重映了，这样说来，是不是《风之谷》也可以期待一下了。
