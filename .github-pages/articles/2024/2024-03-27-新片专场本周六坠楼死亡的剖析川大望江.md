#  「新片专场」本周六 ·《坠楼死亡的剖析》· 川大望江

**写在前面**  
死亡引发的婚姻剖析和自我解读，真相与谎言，公正与偏见，孤独与爱，它不是妥协和屈服，而是从始至终的战斗宣言。它以极小的切口叙事，逐渐如飓风般席卷所有，它不是一层一层的剥开，而是直接破开。  
以悬疑和家庭两部分互相牵制，戳开婚姻生活的层层面纱，虚虚实实，正反交织的迷宫，让观众直到最后依然只看到判决而看不到真相。

**放映员说**  
今年戛纳电影节上，金棕榈大奖的桂冠被《坠楼死亡的剖析》这部影片摘得，可谓实至名归。这也是戛纳电影节历史上第三次女性导演荣获此殊荣。  
影片从一个看似自杀的谋杀坠楼事件入手，深入剖析了男女主角的婚姻生活，层层抽丝剥茧，让人叹为观止。剧本的功力堪称一绝。悬疑案件与婚姻剖析的完美结合，让人在紧张刺激的情节中，感受到了深刻的情感剖析。  
《坠楼死亡的剖析》通过丰富而清爽的镜头语言，以及极具张力的法庭戏剧，成功征服了所有观众的心。影片既通俗易懂，又不失艺术魅力，既有类型元素，又不落俗套，兼具文学性的深度和故事性的锋利与温柔。  
法庭对峙中的激烈博弈，如同一场现实版的主权争夺战，而夫妻间作家身份的设计，更是凸显了这一点。丈夫的创作力枯竭，而妻子却能化腐朽为神奇；丈夫试图改变生活却以失败告终，而妻子却在挫折中找到了新的爱与激情。法庭上，男检察官咄咄逼人，而妻子则凭借自己的叙述成功翻盘。  
在这部多层次的交织作品中，虽然主线是法庭戏，但影片传达给观众的却并非简单的对错与善恶，而是一种态度，一种生活的姿态。这种姿态与性别无关，让人在观看后感到如获新生。总之《坠落死亡的剖析》不仅是一部成功的电影作品，更是一次艺术的盛宴。它让我们看到了女性导演在电影界的崛起与力量，也让我们对电影艺术有了更深的理解和认识。
