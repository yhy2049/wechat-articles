# 24FRAMES PROJECT

过去这些年，我们在这个城市的角落拉起银幕，放映了无数部别人的佳作，汇聚了3万多名热烈的灵魂。我们因为对电影的极致热爱而相聚成群，而现在，我们想在这个充满温度的社群里，一起创造真正属于我们自己的短片电影。  

24帧短片创作现已正式启动。这是一次从银幕前走向镜头后的冒险，也是一封寄给同类的邀请信。  

作为在成都深耕独立/艺术电影的放映组织，24帧将为这部短片倾注全部的社群力量与资源护航。我们向每一位加入的工作人员承诺，绝不让你的心血在硬盘里落灰。  

最近两周我们陆续搭建了项目筹备组，很高兴有这么多人愿意加入我们一起创作，也欢迎更专业的团队/个人加入我们！［详情请查看长图］
