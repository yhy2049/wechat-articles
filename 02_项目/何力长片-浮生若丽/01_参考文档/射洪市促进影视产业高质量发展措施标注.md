# 射洪市促进影视产业高质量发展措施标注

## 政策概述

**文件名称**：射洪市"引客入遂"促进影视产业高质量发展的措施  
**发布单位**：射洪市文化广播电视体育和旅游局、射洪市财政局  
**发布日期**：2025年5月22日  
**有效期**：2年（2024年7月以来符合条件可参照执行）  
**品牌定位**："拍在射洪"

## 适用对象

在射洪开展影视作品创作、生产、发行、放映、器材租赁、演员经纪、培训、基地运营、后期制作等业务的企业。

**影视作品类型**：电视剧、电影、网络影视剧、纪录片、动画电影、动画片、综艺节目、短剧、微短剧等。

**基本要求**：影视拍摄项目须依法通过审核，取得相关备案许可。

## 重点支持政策（与《浮生若丽》相关）

### 1. 企业落户奖励

**奖励金额**：一次性10万元

**条件**：
- 依法登记落户1年以上
- 有固定办公场所
- 社保人数不低于3人

### 2. 办公用房和仓储补助

**办公用房补助**：
- 标准：最高不超过20元/平方米/月
- 面积：最高不超过500平方米
- 金额：最高不超过12万元/年

**仓储补助**：
- 标准：最高不超过5元/平方米/月
- 面积：最高不超过3000平方米
- 金额：最高不超过15万元/年

**条件**：
- 签订两年以上固定办公场所和仓储场所租赁合同
- 社保人数不低于3人
- "先缴后补"方式

### 3. 营收奖励

**300万元以上**：一次性奖励15万元  
**500万元以上且完成升规入统**：一次性奖励30万元

**说明**：同一企业符合条件可以累加。

### 4. 拍摄奖励（重点！）

#### 4.1 鼓励先行（按项目类型）

**电影、电视剧、网络电影、网络电视剧**：
- 每年奖励前5个，每个10万元
- **条件**：根据完成进度

**投资超500万且首次到射洪拍摄**：
- 增加奖励10万元
- **条件**：在射洪摄制时长占总摄制周期70%以上

#### 4.2 鼓励数量（累计拍摄）

**完成2部电影/电视剧等**：一次性奖励15万元  
**为射洪招引并完成1部电影/电视剧等**：一次性奖励10万元

#### 4.3 鼓励体量（按投资额）⭐重点

| 投资范围 | 奖励金额 |
|---------|---------|
| 30-300万元 | 1-5万元 |
| 300-600万元 | 6-15万元 |
| 600-1000万元 | 20-30万元 |
| 1000-1500万元 | 40-50万元 |
| 1500万元以上 | 60万元 |

**额外奖励**：
- 投资超过2000万元 + 剧组人数超过200人 + 在射洪拍摄周期不低于50天：再增加15万元
- 投资超过300万元 + 剧组人数超过80人 + 在射洪拍摄周期不低于30天：按体量排位，前3名分别奖励40万元、30万元、20万元

#### 4.4 鼓励质量（按主创团队和影响力）

| 条件 | 奖励金额 |
|-----|---------|
| 成熟主创团队（制片人/导演/编剧有5部以上播出作品） | 前3个每个5万元 |
| 主演为知名演员或特约2个以上知名演员 | 前3个每个10万元 |
| 全网流量超过500万 | 前3个每个15万元 |
| 项目登上网络热搜前3名，播放量超过5千万 | 前2个每个20万元 |

### 5. 免费资源支持

**全市公共区域、旅游景点均向剧组免费开放**  
**射洪市文化广播电视体育和旅游局负责统筹协调剧组拍摄服务工作**

### 6. 群演补贴

**补贴标准**：20元/人/天  
**总额限制**：不超过20万元，用完为止  
**群演组织奖励**：在射成立的群演组织，射洪籍群演不低于90%，良好运营一年以上，给予5万元奖励

### 7. 剧本奖励

**反映射洪市特色并正面宣传射洪的原创影视剧本**：
- 短剧类剧本：2万元
- 长剧类剧本：5万元

**条件**：作品上线播出后给予奖励

### 8. 植入广告奖励

**影视作品免费植入本地企业广告**：
- 单平台热度最高值破3000万：20万元
- 破5000万：30万元
- 破亿：50万元

**获奖额外奖励**：
- 国际奖励：最高15万元
- 国家奖励：最高10万元
- 省级奖励：最高5万元

**说明**：单部作品不重复奖励，按照获得最高奖项的原则给予奖励。

## 与《浮生若丽》项目的匹配度分析

### 项目基本情况
- 投资规模：380万元
- 开机时间：2026年9月
- 项目类型：长片电影

### 政策匹配评估

**1. 拍摄奖励（体量奖励）** ⭐高度匹配
- **匹配度**：高
- **预计可争取金额**：6-15万元（380万元属于300-600万元档）
- **条件**：需要在射洪取景拍摄
- **额外机会**：如果剧组人数超过80人且在射洪拍摄周期不低于30天，可参与排位奖励（前3名分别40万、30万、20万元）

**2. 拍摄奖励（先行奖励）**
- **匹配度**：中等
- **预计可争取金额**：10万元
- **条件**：每年前5个完成进度的电影项目
- **挑战**：需要与其他项目竞争名额

**3. 免费资源支持**
- **匹配度**：高
- **价值**：公共区域、旅游景点免费开放，可节省拍摄成本
- **服务**：统筹协调剧组拍摄服务工作

**4. 群演补贴**
- **匹配度**：中等
- **预计可争取金额**：根据实际使用群演数量，20元/人/天
- **条件**：使用射洪籍群演

**5. 剧本奖励**
- **匹配度**：低
- **原因**：需要剧本反映射洪特色并正面宣传射洪
- **建议**：如果剧本有射洪元素，可考虑

**6. 植入广告奖励**
- **匹配度**：低
- **原因**：需要免费植入本地企业广告，且热度要求较高
- **建议**：作为额外收入来源

## 建议行动方案

### 核心策略：在射洪取景拍摄

**理由**：
1. 投资380万元，符合300-600万元档奖励（6-15万元）
2. 可享受免费公共区域和旅游景点
3. 可获得统筹协调拍摄服务
4. 如果剧组规模大、拍摄周期长，可争取更高排位奖励

### 具体行动

#### 1. 前期准备（2026年6月-8月）

**考察射洪拍摄资源**：
- 联系射洪市文化广播电视体育和旅游局
- 了解可用公共区域和旅游景点
- 评估拍摄条件和成本

**调整拍摄计划**：
- 如果决定在射洪拍摄，需要调整剧本或分镜
- 规划拍摄周期（建议不低于30天）
- 规划剧组规模（建议超过80人）

#### 2. 申报准备（2026年9月开机前）

**企业注册**：
- 如果计划长期在射洪发展，可考虑在射洪注册企业
- 如果只是单次拍摄，可不注册

**材料准备**：
- 影视作品备案许可
- 投资证明材料
- 剧组人员清单
- 拍摄计划

#### 3. 拍摄期间（2026年9月起）

**配合当地媒体访谈**：
- 争取"质量奖励"（5-10万元）
- 需要有知名演员或成熟主创团队

**使用射洪籍群演**：
- 争取群演补贴（20元/人/天）

**植入本地企业广告**：
- 如果有机会，可争取植入广告奖励

#### 4. 拍摄完成后（2026年底-2027年）

**申报奖励**：
- 按照申报程序提交材料
- 等待评审和公示

## 重要时间节点

- **2026年7月1-31日**：第二个申报周期集中申报（2025年7月-2026年6月符合条件的项目）
- **2026年9月**：计划开机
- **2027年7月1-31日**：第三个申报周期（预计）

## 风险提示

1. **名额限制**：每年奖励总额600万元，用完即止
2. **单一企业上限**：在一个奖励年度内，同一企业、同一剧组奖励最高不超过200万元
3. **拍摄地点要求**：必须在射洪取景拍摄
4. **申报周期**：需要在规定时间内申报
5. **负面舆情风险**：影视作品播出后出现负面效应，不再享受政策

## 成本效益分析

### 在射洪拍摄的潜在收益

**直接奖励**：
- 体量奖励：6-15万元（380万元投资）
- 先行奖励：10万元（如果争取到名额）
- 排位奖励：20-40万元（如果剧组规模大、周期长）
- 群演补贴：根据实际使用量

**间接收益**：
- 免费公共区域和旅游景点
- 统筹协调拍摄服务
- 当地媒体宣传

**总计潜在收益**：16-65万元（不含间接收益）

### 在射洪拍摄的潜在成本

**额外成本**：
- 交通和住宿（如果剧组从外地前往）
- 可能需要调整剧本或分镜
- 当地协调成本

**成本节省**：
- 免费拍摄场地
- 群演补贴
- 当地服务支持
