# 《北回归线以北》成都观影团执行协议

## 甲方（出品方/发行方）
《北回归线以北》出品方
联系人：张勇

## 乙方（执行方）
24帧
联系人：宇航员

---

## 一、合作内容

甲方委托乙方在成都执行《北回归线以北》免费观影团活动一场。

### 1.1 活动信息

| 项目 | 内容 |
|------|------|
| 电影 | 《北回归线以北》 |
| 活动日期 | 2026年6月10日 |
| 活动城市 | 成都 |
| 影城 | [甲方提供，待确认] |
| 影厅规模 | 150座 |
| 预估到场人数 | 约120人（按80%上座率） |
| 活动性质 | 免费观影，口碑场 |
| 场次定位 | 成都四场中唯一面向社会公众开放场 |

### 1.2 甲方责任

1. **影院对接**：负责影城选定、场地费用支付及影院沟通
2. **官拍人员**：派遣官方摄影到场，配合乙方完成活动影像记录
3. **物料支持**：提供战报图设计模板供乙方参考
4. **费用支付**：向乙方支付执行费人民币3000元整
5. **合同发票**：提供合作协议及开具发票（如需）

### 1.3 乙方责任

1. **现场主持**：负责映前暖场、映后互动环节主持
2. **观众招募**：通过自有渠道招募观众，按甲方要求筛选（详见第二条）
3. **物料设计**：负责海报、票根、战报图的设计制作
4. **映后互动**：现场随机提问为主，先抛砖引玉引导导演/主创热场，再将话筒交予观众
5. **现场拍摄**：配合甲方官拍完成活动记录

---

## 二、观众筛选标准

1. 年龄层倾向40岁以上
2. 有医疗背景（医生、外科医生等）优先
3. 房车旅行达人、旅游类博主欢迎
4. 房车企业/品牌合作：需甲方另行确认权限后执行，乙方现场不做任何品牌露出

## 四、映前物料

1. **票根**：乙方负责设计印制，映前发放
2. **海报**：乙方负责设计，用于观众招募
3. **提问准备**：甲方如有特殊提问方向需提前提供；如无，乙方按随机提问模式执行

---

## 五、映后产出

1. **战报图**：乙方负责制作，参考甲方提供的模板格式
2. **活动照片**：甲方官拍 + 乙方自拍，双方均可用于宣传

---

## 六、其他约定

1. 甲方如有主创到场的特殊要求，需提前3个工作日告知乙方
2. 观众招募情况乙方每日同步甲方
3. 活动影像资料双方均可用于各自宣传渠道
4. 如遇不可抗力导致活动取消，双方另行协商
