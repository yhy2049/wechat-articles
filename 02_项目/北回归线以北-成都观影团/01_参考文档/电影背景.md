# 《北回归线以北》电影背景

| 项目 | 内容 |

| 片名 | 《北回归线以北》 |
| 导演 | 赵汉唐 |
| 定档 | 2026年6月19日全国公映 |
| 类型 | 公路情感电影 |
| 主演 | 任达华、王姬、赵汉唐、江一燕、朱宏嘉、索朗旺姆、李依蒙、刘杰毅 |

## 影片定位

华语电影史上首部呈现房车旅行生活、探讨未来多元生活方式的原创故事片。聚焦当代人普遍的情感困境，以三条环环相扣的房车旅行故事线串联婚姻、亲情、自我成长等大众共鸣议题。

## 三条故事线

1. **落魄旅拍摄影师 × 自闭症女儿**（赵汉唐饰）：父亲带着自闭症女儿踏上高原，寻找野生雪豹
2. **退休医生的"青春之旅"**（王姬饰）：横跨多省自驾游，靠随手拍风景短视频意外走红
3. **陪读妈妈 × 抗拒留学的儿子**（江一燕饰）：母子在房车内争吵落泪，隔阂与和解

三组陌生人最终交汇于北回归线以北的辽阔土地上。预告片中有两辆重型卡车突然相撞跌落悬崖的震撼镜头，剧情悬念：意外还是预设？

## 拍摄特点

- 延续导演处女作《七十七天》对户外美学的追求
- 转辗大半个中国实景拍摄：西藏羌塘无人区、新疆和田昆仑山、青海柴达木盆地等十余省市
- 多个壮美场景首次呈现在大银幕上
- 三款房车与人物身份相得益彰：四驱重卡越野房车（摄影师）、城市自驾款（退休医生）、居家型房车（陪读父母）

## 导演背景

赵汉唐，户外探险旅行者与电影创作者双重身份。极地探险院线电影《七十七天》以较低排片成为当年票房黑马，开创华语户外题材电影新类型，获国内外十余项奖项。《北回归线以北》是其第二部户外题材电影。2024年入围金鸡电影创投。
