# 《北回归线以北》成都观影团 · 现场执行 Checklist

> 2026/6/10 活动当天使用
> 影城地址：待确认（需张勇提供）
> 影厅：150座 | 预估到场：120人

---

## 一、出发前检查（出门前逐项勾）

- [ ] 票根已印制 → 数量：至少130张（含余量）
- [ ] 签到表打印（姓名 + 电话 + 来源渠道，用于复盘）
- [ ] 笔（至少3支，总有观众没带）
- [ ] 24帧俱乐部二维码立牌/桌牌
- [ ] 手机满电 + 充电宝
- [ ] 映后提问参考卡片（打印或存在手机里）
- [ ] 现场拍摄设备（相机/手机确认有足够存储空间）
- [ ] 活动流程速查单（可夹在笔记本里）

---

## 二、到场后执行（建议提前1小时到）

### 15min：与影院对接
- [ ] 找到影院对接人，确认影厅编号
- [ ] 确认放映设备是否正常（提前试播预告片/片头广告）
- [ ] 确认话筒/音响（宇航员主持用）
- [ ] 确认签到台位置

### 30min：布置签到区
- [ ] 摆好签到表 + 笔
- [ ] 放置24帧二维码立牌
- [ ] 票根分好：一人一张，入场时发放
- [ ] 如与发行方官拍沟通：确认拍摄位置和走位

### 15min：开映前暖场
- [ ] 观众入座约七八成时，宇航员站到前方
- [ ] 简单自我介绍 + 感谢到场
- [ ] 预告片/信息提醒：观影期间手机静音
- [ ] 播放正片

---

## 三、映后互动（110分钟后）

- [ ] 主持人上台，感谢大家留到映后
- [ ] 按提问指南抛出第一个问题
- [ ] 控制每个话题3-5分钟
- [ ] 注意时间：整个映后控制在20-30分钟
- [ ] 收尾：感谢发行方张勇 + 影城方
- [ ] 提醒：6月19日全国公映，欢迎大家带朋友二刷

---

## 四、散场收尾

- [ ] 引导观众扫码入群（24帧俱乐部）
- [ ] 回收签到表（复盘用）
- [ ] 与官拍确认：照片/视频素材交接方式
- [ ] 收齐物料（剩余票根、签到表、立牌）
- [ ] 与影院确认是否有其他费用需结算

---

## 五、活动后 24 小时内

- [ ] 制作战报图（参考张勇提供的模板）
- [ ] 整理现场照片（精选5-10张）
- [ ] 复盘记录：实际到场人数、观众反馈、执行中遇到的问题
- [ ] 发送战报给张勇 → 确认执行费结算流程
- [ ] 归档至 24帧运营库

## 七、风险预案

| 风险 | 应对 |
|------|------|
| 到场人数太少（<60人） | 场子冷不影响流程正常走；互动环节多引导主创发言 |
| 设备故障（话筒/投影） | 提前确认可用性；话筒无声就脱稿主持，声音够大即可 |
| 观众离散快，映后无人留 | 映前预告"映后有惊喜环节"，提高留存率 |
| 停车场/路线不好找 | 提前踩点，在群里发导航指引 |
