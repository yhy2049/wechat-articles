# 短片众筹/赞助方案设计参考

> 为 24帧首部短片《弄死一条过》的赞助方案（谢琌负责，6/6 截止）提供实操参考。
> 参考渠道：摩点众筹指南、kickstarter 独立电影众筹经验、国内独立电影众筹实践案例。

---

## 一、票档设计原则

### 核心策略

| 原则 | 说明 |
|------|------|
| **5-8 个档位** | 不宜太多，否则支持者选择困难 |
| **价格区间覆盖全** | 从几十元到上千元，照顾不同能力 |
| **100-200 元设主力档** | 摩点统计这个区间转化率最高 |
| **拉开层次** | 每档差距明显，回馈逐级递增 |
| **早鸟档限时限量** | 制造稀缺感，刺激早期转化 |

### 参考票档结构（5000 元预算目标）

| 档位 | 金额 | 定位 | 回馈内容（建议） |
|------|------|------|------------------|
| 🥚 精神支持 | ¥19.9 | 入门门槛 | 电子感谢信 + 片尾致谢名单 |
| 🎬 观众档 | ¥49 | 主力人气 | 以上 + 数字版海报 + 成片观看链接 |
| 🎞️ 铁粉档 | ¥99 | 主力转化 | 以上 + 实体纪念票根 + 幕后花絮电子册 |
| ⭐ 深度参与 | ¥199 | 核心支持 | 以上 + 片尾特别鸣谢 + 剧组电子日报 ×3 |
| 🎥 联合出品 | ¥499 | 高阶支持 | 以上 + 实体纪念册 + 首映礼邀请函 ×1 |
| 🎬 荣誉制片 | ¥999 | 头部支持 | 以上 + 署名"联合出品人" + 剧组探班 + 首映红毯 |
| 企业/机构赞助 | ¥2000+ | 品牌合作 | 片尾品牌露出 + 联合宣发 + 线下活动曝光 |

## 二、回馈内容设计清单

### 零成本/低成本回馈（优先使用）

- 片尾致谢名单（文字）
- 电子感谢信/证书
- 数字版海报
- 幕后花絮照片集
- 剧组创作手记
- 成片数字版/在线链接

### 中成本回馈（需预算）

- 实体纪念票根/明信片
- 实体纪念册/手册
- 首映礼邀请函
- 剧组限定周边（贴纸、徽章等小物件）

### 高价值回馈（限量）

- 片尾特别鸣谢（单独署名"
特别感谢"）
- 探班体验
- 与主创共进晚餐/交流
- 首映红毯位
- 联合出品人/监制署名
- 企业品牌植入（适合机构赞助）

## 三、执行流程（参考时间线）

### 准备期（发布前 1-2 周）

1. 确定预算清单（制作成本 + 回馈成本 + 平台费用 + 运费）
2. 设计票档结构与回馈内容
3. 准备页面素材：封面图、文案、视频预告
4. 预热社群（24帧现有成员、朋友圈、小红书）

### 上线期（D1-D7）

- **D1 黄金48小时**：动员核心圈子第一时间支持，冲热度
- D3-D7：持续更新进度，发布团队介绍、幕后照
- 头部支持者单独维护

### 冲刺期（D7-D14）

- 倒计时提醒
- 解锁目标公布（如达成 150% 解锁什么额外回馈）
- 定向私信未支持的联系人

### 收尾期

- 逐一致谢
- 统计邮寄信息
- 安排回馈制作/寄送

> 短片众筹建议周期：14-21 天（速战速决，不宜拖太久）

## 四、国内可用平台

| 平台 | 适合场景 | 费用 | 备注 |
|------|----------|------|------|
| **摩点** | 文创/影视项目 | 5% 平台费 + 支付手续费 | 国内最大众筹平台，有成熟用户 |
| **小红书** | 内容种草+私域转化 | 免费（自有引流） | 适合预热、传播，不直接收钱 |
| **微信群** | 私域/熟人圈 | 0 | 24帧核心成员+观众，转化率最高 |
| **朋友圈** | 口碑传播 | 0 | 配合海报传播 |
| **B站** | 年轻受众 | 0 | 适合发预告片引流 |

> 组合策略：小红书做内容铺垫 → 私域/微信群做核心转化 → 摩点做公域补充

## 五、风险提示

1. **回馈成本核算**：每档回馈的实际制作+邮寄成本不应超过该档金额的 30-40%
2. **避免过度承诺**：不要给出超出团队能力范围的回馈（如"定制周边"但无打样渠道）
3. **版权问题**：回馈内容中使用音乐、字体等需确认版权
4. **众筹 vs 赞助**：明确区分"众筹"（大众小额参与）和"赞助"（机构/品牌大额合作）的策略差异

## 六、参考案例

> 以下为国内独立短片/小成本电影常用的赞助回馈结构，非特定案例复制，而是综合多部作品提炼的通用手法：

- **¥19.9 精神支持**：降低参与门槛，让更多人成为传播节点
- **¥49-99 标准档**：实体纪念票根/海报是标配，成本低、参与感强
- **¥199 核心档**：首映邀请函能有效激励本地支持者
- **¥499+ 高阶档**：署名权对支持者有很强的吸引力，尤其是同行业/兴趣群体
