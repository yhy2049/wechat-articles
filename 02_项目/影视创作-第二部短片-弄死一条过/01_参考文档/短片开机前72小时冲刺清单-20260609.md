# 短片开机前72小时冲刺清单

> 适用于距离开机还剩3天的紧迫节点。
> 融合自《短片开机前一周筹备检查清单》中"最后一公里"部分并细化到小时级粒度。
> 参考：多位独立制片人的实战经验与影视行业标准制片流程

---

## 一、倒数72小时：核心目标 — 锁定一切变量

开机前3天，所有"可能做"必须变成"已确定"。这个阶段的敌人是模糊和侥幸。

### 人员最终确认（最优先）

- [ ] **演员档期最终确认**：群内/电话逐个确认到场时间，发明确的集合地点+时间+交通方式
- [ ] **剧组核心成员到位确认**：摄影/录音/灯光/场务，每人确认自己携带的设备清单
- [ ] **备份联系人**：每个岗位至少知道一个备份人选（哪怕是业余帮手）
- [ ] **保险确认**：设备保险/人员意外险是否已购买或正在走流程

### 场地最终确认

- [ ] **拍摄场地再次踩点或确认**：确认可用时段、电源位置、噪音时段、邻居/管理处知悉
- [ ] **室内场景：钥匙/门禁/进出权限确认**
- [ ] **室外场景：天气预案**（查拍摄日天气预报，准备室内替代方案或防水方案）
- [ ] **交通路线确认**：从集合点到片场的路线、停车位置、设备运输方式

### 设备清单最终核对

- [ ] **摄影设备**：机身/镜头/存储卡/电池/充电器/监视器/三脚架/稳定器
- [ ] **灯光设备**：灯体/柔光附件/灯架/电源线/备用灯泡/镇流器
- [ ] **录音设备**：麦克风/挑杆/录音机/耳机/备用电池/记忆卡
- [ ] **其他**：反光板/黑旗/大力胶/魔术腿/色纸/沙袋（防风防倒）
- [ ] **食物与水**：剧组餐饮方案确认（预算/人员/过敏/素食）

---

## 二、倒数48小时：核心目标 — 排演与技术验证

### 演员排演（如可行）

- [ ] **通读剧本**：全体演员+导演通读一遍，发现台词问题
- [ ] **关键戏份走位排练**：至少预演一遍复杂调度段落
- [ ] **表演方向沟通**：导演给每个角色一句话的核心状态提示
- [ ] **造型定妆**：服装/妆容确认，拍定妆照存档

### 技术验证

- [ ] **设备充电**：所有电池充满，确认充电器数量足够同时充电
- [ ] **存储卡格式化**：全部清空并测试写入速度
- [ ] **同期录音测试**：在拍摄场地或相似环境录一段，检查底噪和干扰
- [ ] **LUT/监看风格预设**：摄影指导确认监看LUT加载完毕
- [ ] **分镜本最终打印**：纸质分镜表+剧本打印装订，每人一份

### 后勤

- [ ] **药品/急救包**：创可贴/止痛药/防暑/防蚊/肠胃药
- [ ] **天气预报再核对**：精确到拍摄时段的逐小时预报
- [ ] **通信方案**：剧组群置顶公告已发出，集合信息已固化

---

## 三、倒数24小时：核心目标 — 不添乱，睡好觉

倒数24小时内的行动原则：**只做必要的事，停掉所有"锦上添花"。**

- [ ] **设备装包**：按拍摄顺序装好设备，优先装第一镜要用的
- [ ] **备好开拍第一镜**：导演和摄影确认第一镜拍什么（通常选最简单的建立信心）
- [ ] **通知全体集合信息**：群发最终版集合时间/地点/带什么/穿什么
- [ ] **自己休息**：早睡，定好闹钟
- [ ] **备份手机电量方案**：充电宝充满

---

## 四、拍摄日当天原则

### 开拍前

- 提前30分钟到场（导演提前1小时）
- 到场先检查场地情况、电源可用、噪音水平
- 设备通电测试一遍
- 召集全员做3分钟碰头会：今日目标+时间节点+安全须知

### 拍摄中

- **先拍容易的**：第一镜选最简单的场景，建立默契和信心
- **拍完一个场景再换**：不要因为等待而出片场混乱
- **及时备份素材**：每拍完一个场景或存储卡满后立刻备份到硬盘（不急的话收工统一备份也可以，但不要在换卡时翻车）
- **保持食物和水供应**：剧组饿着干活效率减半
- **记录拍摄日志**：每镜拍了几条、哪条可用，收工后省大量时间

### 遇到问题

| 常见问题 | 应对 |
|---------|------|
| 演员迟到 | 先拍不需要该演员的镜头（空镜/其他角色/特写） |
| 设备故障 | 摄影组必须有备用方案（手机也能拍、录音机也能录） |
| 天气突变 | 室内替代方案提前备好 |
| 现场意见分歧 | 导演终裁权，不要在现场辩论超过3分钟 |
| 时间超支 | 保留核心镜头，砍掉"锦上添花"的补充镜头 |

### 收工后

- 素材统一拷贝到备份硬盘
- 确认明日集合时间
- 发布收工公告，感谢全员
- 清点设备，确认无丢失

## 六、一句话哲学

> 独立短片拍摄没有"完美"，只有"拍到了"。
> 好的执行比好的创意更难，但也更值钱。

这一周你投入的一切——众筹、分镜、灯光、声音、配乐——到了拍摄日那天，全部落地在**能不能稳住现场、能不能保持节奏、能不能在出问题时快速决策**这三件事上。技术可以补，节奏乱了就真乱了。
