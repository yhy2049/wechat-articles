# 短片开机前一周：筹备检查清单

> 针对《弄死一条过》的实操参考。预算5000元，6/12开机，6/5人员招聘截止后进入筹备周。

---

## 一、本周核心节奏

| 时间节点 | 该干嘛 |
|---|---|
| **6/5（五）** | 人员到位确认 → 制片统筹拉群 → 发剧本最终版 |
| **6/6-6/7（六日）** | 导演拉排拍表 → 各组分头出需求清单 → 联系场地设备 |
| **6/8-6/9（一二）** | 场勘（带各组组长实走）→ 确认拍摄顺序 |
| **6/10（三）** | 定妆定装 → 演员排练/读本 → 设备试机 |
| **6/11（四）** | 发首日通告单 → 最终确认所有细节 |
| **6/12（五）** | **开机** |

---

## 二、制片要拉的几张核心表

### 1. 场景顺序表（顺场表）

按剧本顺序列出每一场的：
- 场号、地点、内外景、日夜
- 出场角色
- 主要道具
- 特殊需求（烟雾/雨戏/特殊光效）

**目的**：让所有人对影片全貌有一致理解。

### 2. 排拍表（拍摄日程表）

把顺场表按效率重排，遵循三原则：

1. **同场地集中拍**：先把所有A场地的戏排一天，避免来回搬家
2. **同演员集中拍**：协调演员档期，尽量把某演员的戏压缩在少数几天
3. **外景优先、内景靠后**：外景受天气/光线限制，先拍更保险

小成本剧组一天能拍的量 ≈ 6-8场戏（情境剧）或 3-5场（有动作/特殊效果的戏）。

### 3. 每日通告单（Call Sheet）

每天拍摄前发出，包含：
- 集合时间地点
- 当天拍摄场次列表
- 各演员到场时间（精确到分，分"通告时间"和"拍摄时间"）
- 所需设备清单
- 交通方式/停车/餐饮安排

---

## 三、场地筹备（6/5-6/8）

### 确认事项清单

- [ ] **场地是否已锁定**：签约或口头确认都行，但要有后备方案
- [ ] **拍摄时段是否可用**：几点到几点？有没有其他活动冲突？
- [ ] **拍摄许可**：公共场所是否需要报备/申请？私人物业有没有房主同意？
- [ ] **用电条件**：有没有插座？需要发电机吗？
- [ ] **噪音控制**：周围有没有敏感住户？会不会被投诉？
- [ ] **交通动线**：器材车怎么停？人员出入路线？
- [ ] **卫生间/休息区**：最容易被忽略但最致命

### 场勘（6/8-6/9）

场勘时各组组长必须到齐，带着剧本和分镜，每一个镜头过一遍：
- 摄影：确定机位、构图可行性、光线方向
- 灯光：电源位置、是否需要补光设备
- 收音：环境噪音评估、无线麦信号是否稳定
- 美术：场景现状拍照，确定布置方案和还原方案

---

## 四、设备租赁（6/5-6/9）

### 5000元预算的设备策略

这个预算下，设备尽量走"借+租"组合：

| 设备 | 策略 | 参考 |
|---|---|---|
| 摄影机身 | 借或用已有设备 | Sony A7S3 / BMPCC 4K 级别 |
| 镜头 | 租1-2天主力镜头 | 定焦组（35mm/50mm/85mm）比变焦便宜又好用 |
| 灯光 | 租基础三灯组 | LED面板×2 + 聚光灯×1，够小场景用 |
| 收音 | 借+租 | 挑杆+枪麦（必备）、小蜜蜂×2、录音机 |
| 稳定器/滑轨 | 按需租 | 有运动镜头就租，纯固定机位可省 |

**关键动作**：
- [ ] 列设备清单，找2-3家询价对比
- [ ] 租期确认（提前一天进、拍摄当天还）
- [ ] 试机安排（6/10所有设备到齐后试拍确认正常）
- [ ] 备份方案：备用电池至少多备50%、存储卡至少多备一份

---

## 五、演员管理（6/5-6/11）

### 时间线

**6/5-6/6**：确认所有演员档期，发剧本最终版（如果有修改）

**6/7-6/9**：
- 导演单独约每个演员聊天（了解个人状态、激活角色感）
- 布置"演员功课"：写角色日记、回忆相关生活经验
- 如有多位主演，安排一次集体见面/桌游/吃饭（建立默契）

**6/10**：
- 定妆：服装试穿 → 拍照确认 → 微调
- 读本：全组一起读一遍剧本（演员+导演+摄影+录音都到）
- 排练：走第一天的戏，发现潜在问题

**6/11**：
- 最终确认演员集合时间
- 发通告单
- 再次提醒第二天集合时间和地点

### 低成本小技巧

- 演员没车？安排顺风车或报销打车费（比让人迟到划算）
- 演员紧张？提前让他们熟悉片场环境，知道各组都在干嘛
- 素人演员？多给鼓励方式，少给演技指导，多给情境描述

## 六、后勤保障清单

### 食品
- [ ] 早餐（集合到开拍之间的补给，面包/包子/牛奶即可）
- [ ] 午餐（订盒饭/外卖，提前一天下单确认送达时间）
- [ ] 零食/饮用水（全天保持供应）
- [ ] 素食/忌口统计（提前问所有人）

### 交通
- [ ] 集合地点确认（地铁口/停车场定位）
- [ ] 设备搬运动线规划
- [ ] 换场交通安排（连人带设备怎么走）

### 每日收工
- [ ] 当日素材备份（至少双重备份：硬盘+云盘）
- [ ] 第二天通告确认
- [ ] 设备充电/归位
- [ ] 场地复原检查

## 七、应急预案

| 问题 | 应对 |
|---|---|
| **演员临时来不了** | 提前知道、调整拍摄顺序，先把没有该演员的戏拍了 |
| **天气突变** | 外景→改内景/改期，提前看天气预报，备Plan B |
| **设备故障** | 备用机/备用镜头，提前确认最近能救急的租赁点 |
| **场地临时不让用** | 制片随身带3-5个备选场地信息，打电话就能换 |
| **超时** | 每天留1-2小时缓冲时间在排拍表里 |

## 八、小预算短片团队分工参考

小团队往往一人多职，建议明确谁负责什么：

| 角色 | 职责 |
|---|---|
| **导演** | 分镜/导戏/最终决策 |
| **制片/统筹** | 场地/设备/后勤/通告单/协调（这是剧组的大管家，别让导演分心） |
| **摄影** | 画面/机位/镜头选择 |
| **灯光** | 灯光方案/设备操作 |
| **收音** | 现场收音/音效采集 |
| **美术/服化** | 场景布置/道具准备/演员造型 |
| **场记** | 记录每一条的细节（连戏、镜头号、备注）——小剧组常忽略，但后期很需要 |
| **DIT（数字影像技术）** | 素材备份/转码/格式管理 |
