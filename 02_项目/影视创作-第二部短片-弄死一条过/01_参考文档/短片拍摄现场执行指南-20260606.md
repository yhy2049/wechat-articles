# 短片拍摄现场执行指南

> 距《弄死一条过》6/12 开机还有 6 天。
> 与《短片开机前一周筹备检查清单》互补——那篇讲"出发前准备什么"，这篇讲"出发后怎么跑"。

---

## 一、三条原则

1. **准备越细，现场越轻松。** 现场90%的混乱来自筹备期没想清楚的事。
2. **片场时间就是钱。** 低预算短片的容错窗口非常窄，每浪费1小时，可能意味着第二天赶工或超预算。
3. **沟通即效率。** 所有问题早10分钟说清楚，比在现场喊10分钟有用。

---

## 二、拍摄前必须拉出来的三张表

### 2.1 场景顺序表（顺场表）

按剧本出场顺序，逐场列出：

| 字段 | 说明 |
|------|------|
| 场号 | 剧本原有编号 |
| 内/外 | Interior / Exterior |
| 日/夜 | Day / Night |
| 地点 | 具体拍摄位置 |
| 角色 | 该场出现哪些演员 |
| 道具 | 所需特殊道具 |
| 页数 | 剧本页数（估时长用，1页≈1分钟成片） |

**作用：** 让你看清剧本全貌，知道有哪些场景、各场景需要什么。

### 2.2 排拍表（拉表）

把顺场表按**拍摄顺序**重新排列。排序逻辑：

- **场地优先：** 同一个地点能拍的场集中拍完（不管剧本顺序）
- **演员优先：** 某个演员只有半天有空，先把TA的场全部拍掉
- **天气依赖：** 外景日戏优先排晴天，外景夜戏可往后放
- **光照连贯：** 同一场戏的镜头尽量连续拍，避免光不接

```
Day 1（6/12 周六）
  09:00-12:00 场次 001/003/005 — 室内日戏（客厅）
  13:00-17:00 场次 002/004 — 室内日戏（厨房） 
  18:00-22:00 场次 007/008 — 室内夜戏（客厅，灯光重设）

Day 2（6/13 周日）
  07:00-10:00 场次 010/011 — 外景晨戏（公园）
  11:00-15:00 场次 006/009 — 外景日戏（街道）
```

### 2.3 每日通告单（Call Sheet）

拍摄前一天发给全组，说清楚明天的事。核心内容：

| 模块 | 内容 |
|------|------|
| 拍摄日期 / 天气 | 明天几月几日、日出日落时间、天气预报 |
| 集合时间 & 地点 | 精确到分钟，附导航定位 |
| 当天场次清单 | 按拍摄顺序列，含场号、内容、角色、页数 |
| 演员通告时间 | 每个演员几点到、几点收工、是否需要化妆先到 |
| 器材清单 | 当天需要什么机器/镜头/灯光/录音设备 |
| 交通 & 停车 | 停车场位置，公共交通建议 |
| 餐饮安排 | 早餐/午餐/晚餐时间及地点 |
| 剧组通讯录 | 关键人员电话 |
| 特殊注意事项 | 如：现场禁烟、安静时段等 |

> **低预算技巧：** 用 Notion / 飞书 / Google Doc 拉一个模板，每次改日期和场次即可，不用专门买 StudioBinder 付费版。

## 三、现场五步工作法

这是从好莱坞工业体系里沉淀出来的现场执行流程，效率极高。不管团队大小，建议按这个节奏走。

### Step 1：走位（Block）

导演带演员在实景里走戏，定下基本的走位和调度。

**同时做的：**
- 摄影师看机位、定镜头焦段
- 灯光师看光源方向
- 场务做地板标记（演员走位点、机位点）

**给演员上记号：** 用胶带在地面标记 A 演员起始位置、B 演员走到的位置。

> **常见坑：** 导演用手比划"从这里到那里"而不让演员实际走一遍。结果灯光打好后才发现演员站位不对，重新打光浪费30分钟。

### Step 2：打光（Light）

演员撤出，摄影指导带灯光组按定好的机位打光。

**同时做的：**
- 摄影组架机器、铺轨道
- 录音组装无线麦
- 美术组按镜头范围清理现场（穿帮的杂物、反光面）
- 副导安排群演讲戏、协调特效组（放烟/洒水等）

> **省时技巧：** 先用广角全景镜头打光（覆盖范围最大），后面的中近景基本不用大调。

### Step 3：排练（Rehearse）

灯光基本到位后，演员回到演区，按记号完整走一遍。

导演在这个阶段做表演细节调整，不说"再来一遍感觉不对"，而是说"你走到这里时停顿两秒再回头"。

### Step 4：微调（Tweak）

排练满意后：
- 化妆/服装上前补妆、整理
- 跟焦员量距、标记焦点环
- 灯光做最后微调
- 确认一切就绪

> **注意：** 没有经验的造型人员会不自觉地跑到镜头前补妆，副导要控制好时机——等排练完演员归位了再上。

### Step 5：拍摄（Shoot）

正式拍摄。每一条之后：

- 导演给出明确判断：OK 还是再来一条
- 如果要 NG，告诉全组**为什么**（"表演节奏偏快""焦点松了""光穿帮了"），而不是模糊地"再来一遍"
- 通过后，副导安排撤场，准备下一镜

## 四、低预算短片现场避坑清单

### 4.1 时间管理

| 项目 | 建议 |
|------|------|
| 单日拍摄时长 | 不超过12小时（含午餐），第13小时开始全员效率暴跌 |
| 演员化妆先行 | 化妆时间算在通告里，不让全组等演员化妆 |
| 预留缓冲 | 每场戏预估时间上浮30%作为buffer |
| 午饭固定时间 | 不管拍没拍完，到点放饭，饥饿是效率最大杀手 |

### 4.2 沟通纪律

- **片场只通过副导传达指令**，不要7个人同时跟演员说话
- 导演专注创作，制片专注后勤，副导专注现场调度——不要串位
- 关键节点（开拍前、换场时）让全组围拢听2分钟Brief

### 4.3 数据管理

- 每拍完一条，场记确认：场号/镜号/条号/是否OK
- 每天收工前，把当天素材拷到至少两个硬盘
- 手机拍一张"当天拍摄场景布置"的参考照，后期调色/剪辑用

### 4.4 应急准备

| 场景 | 应对 |
|------|------|
| 演员迟到 | 先拍不需要TA的空镜/细节/第二组镜头 |
| 设备故障 | 备一台手机/卡片机作为"最低限度能拍"的方案 |
| 天气突变 | 室内戏排为Plan B，室外戏至少备一个替代室内方案 |
| 有人受伤 | 急救包必须在场（创可贴/冰袋/消毒水/绷带） |

---

## 五、每天收工后必做三件事

1. **素材备份**——当天拍的原始文件至少存两个地方（笔记本 + 移动硬盘）
2. **制片日报**——记录当天拍了多少场、耽误了多久、出了什么问题
3. **明天Brief**——发明天的通告单，确认所有人知道明天几点到哪集合

---

## 六、两句话总结

- **往大处想：** 好莱坞的五步法（Block→Light→Rehearse→Tweak→Shoot），小剧组一样能用，关键是有人严格执行。
- **往小处做：** 三张表（顺场→排拍→通告）+ 每天收工三件事（备份+日报+简报），就能把90%的混乱挡在门外。
