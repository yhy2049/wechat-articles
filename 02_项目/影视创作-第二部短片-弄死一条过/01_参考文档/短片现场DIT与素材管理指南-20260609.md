# 短片现场DIT与素材管理指南

> 创建日期：2026-06-09 | 针对《弄死一条过》悬疑类型、低预算剧组、单/双机位拍摄场景
> 定位：连接「拍摄现场执行指南」与「AI短片后期制作工作流参考」的素材桥梁

---

## 一、DIT是什么，为什么小剧组也需要想这事

DIT（Digital Imaging Technician，数字影像技术员）在大剧组是一个专职岗位，负责从摄影机到后期房的整个数据链路。小剧组请不起专人，但**职责不能省略**——它分散在导演/摄影/场记/导演朋友手里，谁管哪一段事先不约定，拍摄日结束大概率出问题。

典型翻车场景：
- 拍完一天发现某条素材没录上（没检查回放）
- 卡满了格式化前没备份（照片和视频混着拍，格式化时误删）
- 文件名乱编，后期找素材靠"文件名含test的那几段"
- 色温/色彩空间选错，后期调色发现根本拉不回来
- 素材拷贝到硬盘后发现读不出来（坏卡/坏读卡器/坏硬盘）

**小剧组DIT的四个核心原则：**
1. **冗余**——任何素材在删除前至少存在于两个物理介质上
2. **命名规范**——素材文件名=项目缩写+场次+镜次+日期，一天一个命名方案
3. **当日清**——当天素材当天备份、当天检查、当天整理，不留到第二天
4. **纸上留痕**——机内日志 + 场记单 + DIT 交接单，三重记录互锁

## 二、拍摄前准备清单

### 媒体
- [ ] 准备至少 **2张储存卡**（推荐SD或CFexpress，根据机型定），每张容量覆盖半天拍摄
- [ ] 准备至少 **2块硬盘**（1块现场主备份 + 1块异地/第二天带走），推荐SSD 1TB起步
- [ ] 读卡器 × 2（备用一个，读卡器是最高频故障点）
- [ ] 标贴纸+记号笔——每张卡贴序号标签（CARD-01 / CARD-02）

### 设备设置核验（务必拍摄日前确认，开机现场没时间调）
- [ ] 摄影机 **时间码同步**——所有机位日期时间设为同一值（手动统一，或用Tentacle同步器）
- [ ] 确认 **录制格式**（分辨率和帧率符合后期需求，不要拍完发现是60fps 但项目需要24fps）
- [ ] 确认 **色彩空间 / Log曲线**（如S-Log、C-Log、V-Log等，记录在案，后期调色需要知道）
- [ ] 确认 **白平衡**——手动锁定当日基准值（不要Auto，不同镜头间跳色温后期哭死）
- [ ] 确认 **音频通道设置**（机内话筒 vs 外接录音机，声道分配，参考电平）
- [ ] 格式化所有卡（在机身内格式化，不要在电脑上格）

### 场记文档工具包
- [ ] 打印场记单模板（纸质备份）
- [ ] 准备剧照/连续性参考（手机拍即可，用于后期剪辑对照穿帮）
- [ ] 准备 **DIT 交接单**模板（下详）

## 三、拍摄日素材交接流程

### 3.1 卡流转

```
摄影机 ←→ 场记/摄影助理 ←→ DIT/导演 ←→ 硬盘
```

标准流程：

1. **一张卡拍满** → 标记"CARD-XX 满"
2. 交给DIT（或负责备份的人）
3. DIT **完整拷贝**到主硬盘（校验和/大小核对）
4. DIT **完整拷贝**到副硬盘（异地备份）
5. 在电脑上**回放抽查**（至少每个场景抽1条，确认画面声音正常）
6. 场记确认该卡所有内容已备份 → 卡片归还摄影组
7. 机身内**格式化**（不在电脑上格）

> **严禁**：同一张卡上午拍完、下午不清空继续用 — 如果有数据问题，两条拍摄混在一起追查极其困难。

### 3.2 备份额外关注点

- 每天结束后，**副硬盘交给不同的人带走**（不要两块硬盘放同一个包里）
- 如有条件，同步一份到云盘（拍完当天传，虽然慢但防丢）
- 短片素材量通常不大（一整天4-6小时素材约200-500GB），完全可以在拍摄日当晚搞定备份

### 3.3 素材回放检查要点

不只是检查"能不能打开"，要确认：
- 画面无卡顿、无丢帧
- 音频有声音、无爆音、同步正常
- 曝光基本正确（不过曝/欠曝到无法补救的程度）
- 色彩/Log模式正确（有时机内设置会莫名跳回默认）

## 四、文件命名与目录结构

### 推荐命名规范

**方案A：按场次镜次命名（推荐小剧组）**
```
项目名_场号_镜号_次_日期
```
示例：
```
killthefish_SC01_04_T2_20260612.mov
```
含义：《弄死一条过》场景1 第4个镜头 第2条 6月12日

**方案B：按时间码命名（多机位时推荐）**
```
项目名_机位_日期_时间码
```
示例：
```
killthefish_AMA_20260612_140523.mov
```
含义：A机 6月12日 14:05:23 录制

**要点：**
- 文件名中**不要有空格**，用下划线代替
- 日期格式统一 `YYYYMMDD`（6月12日 = 20260612）
- 场号用 `SC01` 而非 `S1`，保证排序不乱
- 反复重拍的镜头，同镜号连续编号（T1/T2/T3）

### 推荐目录结构（一块硬盘上）

```
KillTheFish_ShootDay1/
├── 00_CARD_RAW/           ← 原始卡内文件（只读存档，不修改）
│   ├── CARD-01/
│   └── CARD-02/
├── 01_PROXY/              ← 代理文件（如用DaVinci生成小文件供现场预览）
├── 02_DAILIES/            ← 每日精选/场记标记的可用条
├── 03_AUDIO/              ← 独立录音机素材（假设与机内音分开录制）
├── 04_STILLS/             ← 连续性参考照片、剧照
├── 05_DOCS/               ← DIT日志、场记单扫描件、通告单
└── README.md              ← 当日拍摄摘要（拍了什么、注意事项）
```

> **DIT交接单**（每张卡对应一张，内容需写在纸上或表格中）：
> - 卡编号 / 拍摄日期 / 摄影师签名
> - 总文件数 / 总时长 / 总容量
> - 抽检结果（画面OK/音频OK/异常备注）
> - 备份目标硬盘编号+路径
> - 格式化确认（签名）

## 五、低预算剧组的特殊考量

### 5.1 苹果生态（Mac + FCP 用户）

如果你用Final Cut Pro，注意：
- **不要直接在外置硬盘上剪辑**——拷贝到Mac内置SSD或高速外置盘（雷电3/4接口）再建库
- FCP资源库不要放在备份盘上，资源库结构特殊，容易出权限问题
- 代理文件现场生成建议当晚统一处理，不要边拍边转码（除非人手充裕）

### 5.2 达芬奇用户（DaVinci Resolve）

- 如果拍Log素材，达芬奇可以直接挂LUT预览，但**不要修改原始文件**
- PowerGrade建立统一的调色项目文件，避免各人本地各调各的
- 达芬奇的项目库建议放云盘同步（团队协作场景）

### 5.3 素材量预估参考

《弄死一条过》假设单机位、23-25分钟成片：
- 拍片比假设 10:1~15:1（低预算短片常见范围）
- 原始素材约 3-6小时 → 按4K 10bit计算约 200-600GB
- 代理文件约 50-100GB
- 两块1TB SSD即可覆盖，冗余足够

### 5.4 现场临时翻车处理

| 问题 | 解决方案 |
|------|----------|
| 卡满了还在拍 | 确保拍完一条后立即换卡，中场换卡比临时中断好 |
| 读卡器坏了 | 备用读卡器（十几元一个不贵）|
| 硬盘空间不足 | 拍摄前清理硬盘，只带项目相关文件 |
| 素材复制一半断电 | 不要开机继续复制 → 重新检查完整性和文件数 |
| 发现前一天素材没备份 | 先别格式化那张卡，立即补拷，确认后再处理 |

## 六、拍摄结束到后期交接

### 当天结束时
- [ ] 两块硬盘各有一份完整素材
- [ ] 场记单（电子/纸质）与素材目录对应检查
- [ ] 剪辑师/后期负责人拿到素材拷贝（或通过网盘/硬盘转交）
- [ ] 在项目群里发一条当日拍摄摘要（拍了哪些场景，有无异常）

### 全部拍摄结束后
- [ ] 所有原始素材汇总到**主存储库**（如剪辑师的外置RAID/大硬盘）
- [ ] 按场景/日期建立正式目录结构
- [ ] 场记单整理为电子版（Excel/Airtable），与素材一一对应
- [ ] 原始卡保留至粗剪完成后再格式化（安全冗余期）

## 七、一句话口诀

> **先拷再验、验完再格、格完不拍。两块硬盘、分人带走、当日清空。**
