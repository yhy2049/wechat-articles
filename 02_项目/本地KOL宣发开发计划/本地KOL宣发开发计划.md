# 本地KOL宣发开发计划

## 项目概述

将24FRAMES从观影团运营升级为区域宣传平台。俱乐部已停止运营，小猴与谢琌合并为新业务团队，接手观影团策划+执行。

## 核心定位

**本质是导向区域宣传**——这是最有竞争力和商业价值的定位。

## 团队架构

| 角色 | 人员 | 职责 |
|:----|:-----|:------|
| 总策划+执行 | 小猴 | 放映策划+活动策划+执行落地 |
| 总策划+执行 | 谢琌 | 放映策划+活动策划+执行落地 |
| 创始人 | revachol | 辅助+谈口碑场+KOL资源支持 |
| 策展人 | 策展团队 | 参与活动策划 |

## 即时项目：《冬旅人》8.14 成都路演

- **影片**：冬旅人（燕舞影业）
- **日期**：8月14日
- **费用**：300元执行费
- **模式**：观影团+KOL路径
- **动作**：加入本地KOL招募，后续谈口碑场

## 产品路径

```
当前：观影团（策划+执行 交给小猴+谢琌）
  ↓
第一步：观影团 + KOL（招募本地KOL参与，免费招募）
  ↓
第二步：完全走向KOL招募（而非普通观众）
  ↓
第三步：区域宣传平台（最有竞争力和商业价值的形态）
```

## KOL招募策略

- **免费招募**：KOL参与价格全免，以内容置换代替付费
- **核心逻辑**：KOL产出内容（小红书/朋友圈）→ 扩大传播 → 吸引片方合作
- **辅助资源**：revachol 已有一些KOL资源，持续跟进激活

## 收入模型

| 阶段 | 收入来源 | 说明 |
|:----|:---------|:------|
| 启动期 | 执行费（300元/场）+ 口碑场合作 | 薄利，积累案例 |
| 成长期 | 口碑场+KOL打包服务（3-5万/场） | KOL内容产出提升价值 |
| 成熟期 | 区域宣传平台服务费 | 最有竞争力的形态 |
