# be seen / 草履虫短片影展策划案

> **版本：** 第一稿（2026-06-04 丽云、海坤提交）
> **文件类型：** 策划案原稿
> **说明：** 本文档由 Word 文件转换而来，原文件已删除。后续版本将在此基础上迭代。

一、项目概况

| 项目 | 内容 |
| --- | --- |
| 影展名称 | be seen/草履虫短片影展 |
| 主办方 | 24帧 |
| 项目定位 | 面向川渝高校学生的短片征集、评审与影院展映项目 |
| 参赛对象 | 四川、重庆地区高校学生，含专科、本科、研究生；毕业生作品须在学生身份期间完成 |
| 预计征片 | 100部左右 |
| 最终展映 | 18部，剧情8部、纪录6部、实验4部 |
| 展映周期 | 两个周末，按片长灵活排片 |
| 展映地点 | 优先专业影院，书店、艺术空间作为备选 |
| 报名入口 | 投奖小程序；观众通过报名工具购票 |

二、主题理念

"草履虫"象征微小而持续运动的生命力。学生创作者常常处在设备、预算、时间和协作条件有限的环境中，但他们依然能通过影像表达个人经验、观察现实、提出问题。

本届影展希望把这些微小的创作聚集起来，让学生作品被看见，让年轻创作者彼此连接，也让更多人意识到：微小的力量同样可以产生真实的波动。

三、项目目标

| 优先级 | 目标 | 说明 |
| --- | --- | --- |
| 1 | 提供学生作品展映机会 | 让川渝地区学生短片进入正式观看现场 |
| 2 | 建立川渝学生影像社群 | 通过征片、评审、展映和映后交流建立创作者关系 |
| 3 | 形成24帧青年影展品牌 | 以第一届试水为起点，积累长期项目经验 |
| 4 | 连接外部资源 | 连接影院、书店、媒体和本地品牌资源 |

四、征片规则

| 类别 | 规则 |
| --- | --- |
| 作品身份 | 作品须在创作者学生身份期间完成；团队作品中导演、制片或主要创作者之一符合川渝高校学生身份即可 |
| 投稿身份 | 每部作品仅允许导演或制片投递；同一创作者仅可作为主要投递人提交一部作品 |
| 作品时长 | 单部作品不超过60分钟 |
| 接受类型 | 剧情、纪录、实验影像 |
| 不接受类型 | MV、广告片及以商业宣传为主要目的的作品 |
| AI说明 | 接受AI影像，需注明全片AI生成或AI辅助生成，并说明AI参与环节 |
| 文件格式 | MP4或MOV，暂不设置文件大小上限 |
| 字幕要求 | 须配中文字幕 |
| 提交材料 | 影片、3张剧照、1张海报、主创简介、作品简介、学信网截图 |

五、报名与提交

- 投稿入口为投奖小程序，影片正片与全部材料均通过小程序上传。
- 报名表需填写导演、制片、编剧、摄影、主演等团队信息。
- 报名表单独设置AI使用说明栏。
- 版权声明与放映授权采用勾选确认方式。投稿者须确认作品版权清晰，并授权影展在本届活动周期内用于评审、展映、宣传与非商业推广。
- 征片截止前可修改或补充材料；截止后原则上不再接受作品替换、信息修改或材料补交。
- 投稿成功后由小程序自动确认，入围与展映信息后续另行通知。

六、评审机制

| 阶段 | 执行主体 | 数量规则 | 结果 |
| --- | --- | --- | --- |
| 一、初筛 | 组委会 | 每个单元进入复审的数量约为初审数量的50%；复审总量控制在48部左右，原则上不超过50部 | 剧情约20部、纪录约16部、实验约12部进入复审 |
| 二、复筛 | 大众评审 | 招募偶数位大众评审，分A、B两组；每组审核剧情10部、纪录8部、实验6部 | 每组选出剧情4部、纪录3部、实验2部进行展映 |
| 三、终审 | 3位终审评委 | 三位评委共同评审最终获奖作品 | 在每个单元评选一个奖类 |

**拟邀请评审（职业类型多样性）：**
- 导演 陈小雨，代表作品：《乘船而去》
- 导演 卞灼，代表作品：《翠湖》
- 纪录片导演 顾桃，代表作品：《犴达罕》《在一起》，在《椒麻堂会》中饰演驼儿
- 演员 野兆月，代表作品：《不游海水的鲸》《悠长假期》《六月八号下午五点》，入围FIRST one演员实验室

| 大众评审分组 | 人数 | 审核作品 | 每组入围 |
| --- | --- | --- | --- |
| A组 | 10 | 剧情10部、纪录8部、实验6部 | 剧情4部、纪录3部、实验2部 |
| B组 | 10 | 剧情10部、纪录8部、实验6部 | 剧情4部、纪录3部、实验2部 |
| 合计 | 20 | 剧情20部、纪录16部、实验12部 | 剧情8部、纪录6部、实验4部 |

七、展映安排

- 展映周期为两个周末，具体场次按片长和影院排期灵活安排。
- 鼓励入围主创到场，但不强制。
- 只为重点作品设置映后交流，主创无法到场时可采用线上连线。
- 不设置独立开幕式，最后一场放映后进行闭幕颁奖。
- 后续可以考虑在成都范围内进行书店、文化空间的征集。类似主动放映的形式，将创作者们的作品在成都范围内再一次进行放映和交流。

八、奖项设置

| 类别 | 奖项/机制 | 评选方式 |
| --- | --- | --- |
| 单元奖 | 剧情、纪录、实验三个单元各设置一个奖类 | 三位终审评委共同评选 |
| 24帧推荐奖 | 由24帧团队从入围作品中选择 | 组委会评选 |
| 最受观众欢迎奖 | 由观众投票产生 | 线下现场投票与线上平台投票结合 |
| 惊喜趣味奖项 | 面向所有投稿者设置 | 根据投稿情况设置，如吃螃蟹奖（最早提交）、最会踩点奖（最晚提交）、时长最长等趣味性奖项 |

九、宣传传播

| 渠道 | 用途 |
| --- | --- |
| 24帧公众号 | 发布征片公告、评审介绍、入围片单、展映排片、获奖名单与回顾文章 |
| 24帧视频号、小红书 | 发布影展视觉、征片提醒、现场花絮与短视频回顾 |
| 校园社群与高校社团 | 触达川渝高校学生创作者 |
| 媒体合作 | 本地生活号、电影类公众号、校园媒体、艺术空间账号参与传播，也可邀请为大众评委或现场嘉宾 |
| 线下宣传 | 主要放在影院现场，包括海报、易拉宝、KT板、票根、场刊、展映手册等 |

| 阶段 | 内容 |
| --- | --- |
| 预热 | 主题释义、主视觉预告 |
| 征片开启 | 征片公告、投稿规则、报名入口 |
| 评审公布 | 评审机制、评委信息、大众评审招募 |
| 倒计时 | 征片截止与展映倒计时 |
| 入围片单 | 公布18部入围展映作品 |
| 展映排片 | 发布单元、场次与观众报名方式 |
| 获奖公布 | 发布获奖名单 |
| 回顾总结 | 发布现场图文、短视频与项目复盘 |

十一、预算与合作

本届影展拟收取少量报名费，展映阶段采用低价票。预算来源主要包括赞助、票房收入和报名费。影展计划与川渝本地品牌开展合作，优先考虑青年文化、影像创作、书店空间、咖啡饮品、文创生活等方向。

| --- | --- |
| 影院场地费 | 影厅租赁、放映设备、技术支持 |

| 宣传物料费 | 海报、KT板、易拉宝、票根、场刊、展映手册 |
| 评审交通住宿 | 终审评委线下到场时的交通和住宿 |
| 奖品与证书 | 正式奖项和趣味奖项使用 |
| 现场执行费用 | 签到物料、工作人员餐水、主持、场务消耗品 |
| 摄影摄像记录 | 现场记录、短视频、回顾文章和影像档案 |

十二、风险预案

| 风险情况 | 应对方案 |
| --- | --- |
| 投稿数量低于预期 | 照常举办，展映数量根据作品质量灵活调整 |
| 投稿数量高于预期 | 仍控制18部最终展映作品，保证展映质量与现场节奏 |
| 影院合作未落地 | 以书店、艺术空间作为备选空间 |
| 评委无法线下到场 | 接受线上评审、线上致辞或视频参与 |
| 主创到场人数较少 | 重点作品映后改为线上连线 |
| 票务报名不足 | 通过媒体、校园社群、合作方渠道补充招募 |
| 现场播放故障 | 提前技术测试，准备多格式备份文件与备用设备 |

十三、时间推进表

| 阶段 | 时间 | 工作内容 |
| --- | --- | --- |
| 视觉与评审筹备 | 6月到7月中旬 | 完成主视觉和基础物料设计，推进评委邀请与合作资源沟通 |
| 征片与传播 | 7月中旬到8月中旬 | 开启征片，发布公告，招募大众评审，对接媒体合作 |
| 初筛与复筛 | 8月中旬到9月中旬 | 完成组委会初筛、大众评审复筛、终审评奖准备，确定18部入围片单 |
| 展映筹备 | 9月中旬到9月底 | 确定影院或备选空间，完成排片、物料、观众报名和现场流程 |
| 展映与颁奖 | 9月底到10月中旬 | 两个周末完成展映，设置重点映后交流，最后一场闭幕颁奖 |
| 回顾与复盘 | 10月中旬后 | 发布获奖名单、回顾内容、短视频，整理影像档案与项目复盘 |
