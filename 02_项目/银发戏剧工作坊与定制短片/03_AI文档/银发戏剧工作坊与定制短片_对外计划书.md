# 银发戏剧工作坊与定制短片 · 项目计划书

**24帧 × 孙义 · 2026年10月**

> 这份文件是能力说明和落地方案，不是合作协议。合作期限、场地品牌、设备清单这些写进合同的细节，我们留在合同里确认。这里只讲一件事：这件事怎么做成，以及我们凭什么能做成。

## 一、我们在做什么

两条产品线，一条喂一条。

| | 银发戏剧工作坊 | 定制短片 |
|---|---|---|
| 卖给谁 | 有时间的成年人（银发为主，兼周末可出的家庭） | 企业老板、想留影像的人 |
| 卖什么 | 排练 + 演出 + 参与感 | 一部属于他自己的短片 |
| 怎么收钱 | 课程收费 + 演出分账 | 明码标价，按预算分档 |
| 上线吗 | 不上。只拍切片做引流 | 可上线，走公账、有资质 |
| 现在阶段 | 主线，先跑起来 | 顺位第二，等队伍跑通 |

逻辑很简单：工作坊把人聚起来、把演出练出来，练出来的人就是定制短片的演员班底。定制短片反过来给工作坊一个"能拍电影"的出口，学员才愿意来。

两条线共用一个场地、一支队伍、一套宣发渠道。这是这个项目最省的地方。

## 二、为什么是现在

三个外部信号，都是已经发生的，不是预测。

**1. 政策在往线下推。** 线上时间饱和，政策端明确引导线下消费。线下演艺、话剧振兴是被点名的方向。做正事、有规模、有稳定客户，政府支持会慢慢跟上。

**2. 银发时间成了硬通货。** 老年群体有整块的、可持续的空闲时间。年轻人反而没有。谁先把这部分时间组织起来，谁就先拿到一个别人没有的固定客群。而且老人的时间不挑工作日，排练排班难度低。

**3. 定制需求真实存在。** 企业老板、行业里的人，想用影像记录自己或团队，愿意为此付费。这个需求一直有，缺的是靠谱的执行方和合规的通道。

三个信号叠在一起，这件事的窗口期就是现在。

## 三、边界先说清楚

这一点我们放在前面讲，因为它决定了整件事能不能做起来。

**内容形态：先戏剧，不先影视。**
影视类要上线，得放映权，得广电批准。前期没有这个，做不了。戏剧类是线下演出，边界清晰，风险可控。所以前期所有产出都按戏剧走，切片可以发，但不做影视发行。

**钱必须走公账。**
只要走公账，就必须通过有资质的影视公司。片子不上映也没关系，交付物是片子和版权。一次性买断IP，我方全额出钱雇演员，交完片即脱离后续风险。谁出钱谁有权，多人出资按出资比例分权益。

**学校关系要走正规路径。**
不能私下办班。正确姿势是外来机构以"孵化项目"或"产教一体化"名义参与，学校这边有背书，学员侧也支持。这条路径成立，学校老师才能出面。

**聚集要有凭据。**
以学校名义 + 社会方/公司合作成立主体，持有营业执照作为凭证。制作环节前期报备。这不是走形式，是出事时的第一道防线。

上面四条不是限制，是我们能接这个项目的底气。

## 五、落地路径

四步，一步比一步重。

### 第一步：锁场地

先把一个能长期排练的固定场地拿下来。没有场地，什么都谈不上。

- 首选：有政府文化产业扶持背景的文化空间（这类空间本身有义务做文化内容活动，合作意愿天然更高）。
- 备选：24帧已有的固定放映场地、美术馆单独租赁。
- 演出端：具备舞台和200–400人站位能力的现场。

### 第二步：建生源档案

三条管道并行，不赌一条：

1. 学校侧——学员与在读学生，有专业能力，是演出骨干。
2. 场地侧——会员与到访人流，是稳定观众和潜在学员。
3. 自有侧——观影团观众、KOL内容引流，是把活动变成事件的那一环。

这一步的产出是一份名单，不是一句"我们能招到人"。

### 第三步：workshop 试跑

先上3天短期制，再谈7天制。理由：3天能验证报名意愿、场地可用性、收费接受度，成本几乎为零。7天制适合稳定生源之后再做。

一次 workshop 结束必须有可对外展示的产出：一段成片 + 一组现场照片 + 一次小规模互动演出。这三样东西是下一步招生和卖演出票的全部素材。

### 第四步：首演与转化

首演放在具备舞台条件的现场，公开售票。跑完之后：

- 演得动的队伍，转定制短片班底。
- 跑通的模型，复制到第二个场地。
- 沉淀下来的学员，转长期班底，按年参与、按年分账。

## 六、报价：采纳孙老师的标准

这一节我们直接把孙老师的标准写下来，作为双方的报价原则。

**明码标价，公司费用与制作费用分列成表，客户自己决定签不签。** 不拿"行业价"当幌子，也不靠压成本换低价。

**理由我们认：** 抠得太紧，客户会觉得你在算计他的预算，能花多少钱办多少事。业务会越走越窄。公司正常纳税，成本就是成本，利润应该来自透明的定价，不是来自压缩。

**按预算定服务规模：**

| 预算档 | 交付 |
|---|---|
| 20万级 | 10分钟短片，标准制作规格 |
| 100万级 | 20–25分钟短片或舞台演出记录片，分镜与服化升级 |
| 200万级 | 筹拍电影，完整制作团队 + 报备流程 |

每一档都配一张费用明细表，公司费用（策划、统筹、宣发、管理）和制作费用（摄影、灯光、录音、服化、场地、后期）分开列，客户可以直接砍自己不要的那一栏。

**工作坊侧：** 3天制和7天制两个价格，含排练、场地、道具、结营演出。长期班底按年计，含分账权益。分账比例不在这份文件里写，碰面时谈。
