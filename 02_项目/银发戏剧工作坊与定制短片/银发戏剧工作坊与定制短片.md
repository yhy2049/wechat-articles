# 银发戏剧工作坊与定制短片

## 一句话定位

先线下、后线上，先演出、后拍片。用小酒馆场地和川传生源跑通低成本戏剧工作坊，再把演得动的队伍变成可售票的演出和可卖版权的定制短片。

> 跨方向：主挂 [[观影团]]（场地 + 观众），业务形态延伸进 [[宣发平台]]（区域宣传、KOL引流）与 [[影视创作]]（定制短片、报备与版权）。

## 两条产品线

| 产品线 | 形态 | 收入 | 上线 | 阶段 |
|---|---|---|---|---|
| 银发戏剧工作坊 | 戏剧类，线下演出（7天制 / 3天短期） | 课程收费 + 演出分账 | 不线上分发，只拍切片引流 | 前期主线 |
| 定制短片 | 客户付费定制，我方出团队制作 | 明码标价，按预算分档 | 有资质走公账，不上映也可 | 方向二，与工作坊衔接 |

## 当前阶段

**2026-10-06 首次正式沟通完成。** 方向已口头确认，尚未签任何协议，尚未接触川传老师。当前是"试水期"——先低成本试跑，跑通再加码。

## 风险与应对

| 风险 | 应对 |
|---|---|
| 非法聚众（聚集20/40人无申报） | 走"学校名义 + 社会/公司合作成立公司"，持营业执照作凭证；制作前期报备 |
| 无资质拍摄、线上无放映权 | 必须通过有资质的影视公司走公账；片子不上映也可交付 |
| 学校老师私下办班不合规 | 外来机构以"孵化项目"名义参与，满足学校对产业了解的需求，不走私下班 |
| 早期利润不足 | 宇航员以其他方向填充（见 [[本地KOL宣发开发计划]]、[[何力长片-浮生若丽]] 联合制片）；明码标价不压成本以保毛利 |
| 甲方担心24帧撑不过三个月 | 用四年220+场、联合出品长片在拍、政府文化产业空间关系等已落地事实对冲（见对外计划书 §7） |
| 牛牛12月才能参与 | 11月碰面至12月试跑由孙义与宇航员直接推进，执行类工作留到牛牛返蓉 |
| 场地拿不下来 | 双备份：小酒馆文化空间 + 24帧此前固定的电影院；美术馆单独租赁作为第三选 |
| 生源不足 | 三条管道：川传学生 + 小酒馆会员/政府空间人流 + 24帧观影团观众与KOL引流 |
