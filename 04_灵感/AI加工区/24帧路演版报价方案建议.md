# 24帧「路演版」报价方案 · 完整结构建议

> 编制日期：2026-06-26
> 用途：指导后续Excel报价单制作
> 版本：v1.0（草案）

---

## 1. 核心定位

**一句话定位：**
> 路演版卖的不是一场活动执行——卖的是「片方在成都的信任背书 + 影迷社群的精准触达 + 明星安全落地的执行保障」。

三个不可替代的卖点：
1. **2,000+活跃影迷池+20+微信群** = 片方花钱买不到的真实口碑基础盘
2. **220+场执行经验** = 知道明星场什么环节会出问题，知道怎么不出问题
3. **成都本地深度资源** = 影城协调、安保报批、媒体通道，不需要片方从北京遥控

---

## 2. 报价结构（模块化拆解）

### 总体原则

- **基础套餐** = 「口碑场升级包」模式——路演版 = 口碑场基础版 + 路演专属模块增项
- **全部模块化**：客户可按需勾选，不强制打包
- **分两档**：标准路演（1-2位主创到场）/ 豪华路演（3位以上主创+红毯+直播）

## 3. 定价建议

### 3.1 推荐套餐结构

| 套餐 | 包含模块 | 建议总价 | 适用场景 |
|------|---------|---------|---------|
| **路演基础版** | A+B+F+I（固定项）+ C1 + E1 + G1 + J1 + K4 | **¥25,000-¥28,000** | 1-2位主创到场，小型路演，不要求大阵仗 |
| **路演标准版** ★推荐 | 基础版 + D1-D3 + C2 + G1-G3 + H1-H2 + J2 + K1-K4 | **¥45,000-¥52,000** | 3位以上主创，标准路演场，有本地媒体报道 |
| **路演豪华版** | 标准版 + C3 + G全 + H全 + J3 + 直播推流 | **¥68,000-¥80,000** | 首映礼级，当红明星，全媒体覆盖 |

> 所有价格**不含场租**（场租代收代付），不含片方自带的摄影师/物料。

### 3.2 固定成本 vs 可选成本

**固定成本（始终发生）：**
- 项目统筹（A）：¥6,500
- 现场执行（B）：¥5,700
- 观众运营（F）：¥3,600
- 场地协调服务费（I）：¥1,000
- 基础安保（J1）：¥800
- **合计：¥17,600（硬成本）**

**高弹性可选成本（客户决策）：**
- 摄影摄像（C）：¥2,500-¥13,000
- 灯光音响（D）：¥6,300
- 主持（E）：¥1,500-¥3,000
- 物料（G）：¥3,000-¥7,900
- 媒体（H）：¥5,000-¥9,000
- 安保升级（J2-J3）：¥1,500-¥3,300
- 其他接待（K）：¥2,800-¥5,800

### 3.3 与「口碑场基础版」的关系

**建议策略：路演版 ≠ 独立产品，而是口碑场的「升级方案」**

- 如果客户之前买过口碑场基础版（¥7,900/¥4,900），可以直接加购**路演升级包**（含路演专属模块：D+E+H+J+K部分 + A/B/F升级部分），约¥22,000-¥35,000
- 如果客户是新客且明确要路演，直接推**路演标准版/豪华版**
- 好处：老客看到升级路径清晰，新客看到完整服务价值

## 5. 注意事项与常见坑

### 🔴 高危环节（24帧需提前准备）

#### 5.1 影城协调的「隐形坑」
| 问题 | 后果 | 预防 |
|------|------|------|
| 影城为了卖票擅自加售站票/过道票 | 主创入场拥挤、安全隐患 | 合同明确售票数量上限，影城违约赔偿条款 |
| 影城临时给VIP厅换普通厅 | 主创体验差，片方投诉 | 提前3天书面确认，当天早上再电话确认 |
| 影城保安被抽调到其他活动 | 现场安保人手不足 | 合同注明影城须提供的安保人数，到现场先数人头 |
| 影城开场前临时要求加场租 | 预算超支，难向片方交代 | 场租书面协议，注明「此价格为最终价，无任何附加费」 |

#### 5.2 主创接待的「雷」
| 问题 | 后果 | 预防 |
|------|------|------|
| 主创迟到/航班延误 | 活动整体delay，观众躁动 | 出发前确认，留至少30分钟buffer，准备暖场方案 |
| 主创不接受指定媒体采访 | 媒体白来了，片方尴尬 | 媒体名单/问题提前给片方审核 |
| 粉丝围堵主创车辆 | 安全隐患 | VIP通道+安保前出，不能只守在影城门口 |
| 主创对休息室不满意 | 影响情绪 | 提前拍休息室照片给片方确认，准备好备选方案 |

#### 5.3 现场执行的「关键时刻」
| 环节 | 常见问题 | 对策 |
|------|---------|------|
| 观众入场→主创入场之间的等待 | 观众等太久玩手机，氛围冷 | 安排暖场视频/互动游戏/抽奖，不能让场子冷超过3分钟 |
| QA环节 | 观众问敏感问题/不会提问冷场 | 安排2-3个「托」在观众席，备好问题，冷场时举手 |
| 主创离场 | 粉丝冲台/追出影城 | 主创走VIP通道，安保在厅门口形成人墙 |
| 合影环节 | 粉丝自拍杆打到主创/时间拖太长 | 限定10-15分钟，专人喊场控时 |

#### 5.4 票务的「灰产坑」
| 问题 | 说明 |
|------|------|

## 6. Excel报价单制作指南

### 工作表结构建议

| Sheet | 内容 |
|-------|------|
| Sheet1: 封面 | 方案名称+24帧Logo+一句话定位+联系方式 |
| Sheet2: 模块报价总表 | 所有模块逐行罗列，标注「必选/可选」，支持勾选 |
| Sheet3: 套餐推荐 | 三档套餐的模块组合+总价 |
| Sheet4: 交付物清单 | 每模块的核心交付物 |
| Sheet5: 过往案例 | 精选10-15场路演/口碑场照片+数据 |
| Sheet6: 服务流程 | 路演前/中/后的时间轴 |

### Excel排版要点

- 模块名用粗体+底色区分，方便客户快速浏览
- 单价列加¥符号统一，小计列用SUM公式自动计算
- 每个可选模块旁加「口」勾选框（纸质版）或下拉菜单（电子版）
- 最后附「代收代付清单」（场租、保险等）独立行列
- 方案底页放24帧团队介绍+二维码（公众号+群入口）
