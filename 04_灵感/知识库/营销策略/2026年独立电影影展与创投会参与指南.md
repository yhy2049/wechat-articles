# 2026年独立电影影展与创投会参与指南

**整理时间**：2026-06-07  
**目的**：为24帧品牌提供2026年主要独立电影影展、创投会的参与信息，帮助品牌拓展行业连接、寻求合作机会。

## 一、FIRST青年电影展（西宁）

### 基本信息
- **届数**：第20届
- **时间**：2026年7月（具体日期待官方公布）
- **地点**：西宁
- **官网**：https://www.firstfilm.org.cn

### 参与板块
1. **主竞赛单元**
   - 征集长片（60分钟以上）
   - 报名截止：2026年4月28日 24:00（北京时间）
   - 要求：剧组主创50%以上为中国居民

2. **FIRST FRAME她的一帧单元**
   - 征集长片（60分钟以上）
   - 报名截止同主竞赛单元

3. **FIRST PIONEER先锋创作单元**
   - 征集短片（30分钟以内）
   - 报名截止同主竞赛单元

4. **超短片单元**
   - 征集5分钟以内作品
   - 报名截止：2026年5月31日（北京时间）

5. **创投会**
   - 电影长片项目（预计时长80分钟及以上）
   - 正在开发阶段，无投资或尚未完成全部融资
   - 报名截止：2026年3月31日 23:59（北京时间）
   - 报名费用：早鸟200元，标准400元，延迟800元（人民币）
   - 公开陈述：2026年7月22日-23日（西宁）
   - 一对一洽谈：2026年7月24日-25日（西宁）

6. **产业放映**
   - 征集已完成影片或制作中项目
   - 全片放映：5000元/场
   - 片段放映：3600元/场（2-3部）

### 联系方式
- 创投会：project@firstfilm.org.cn
- 产业放映：industryscreening@firstfilm.org.cn
- 纪录片实验室：doc@firstfilm.org.cn
- 300击·超短片发展计划：shortproject@firstfilm.org.cn

## 二、上海国际电影节（SIFF）电影项目创投

### 基本信息
- **届数**：第28届
- **时间**：2026年6月12日至21日
- **地点**：上海
- **官网**：https://www.siff.com
- **最新消息**：2026年2月柏林电影节期间正式公布具体日期

### 参与板块
1. **类型片项目**
   - 面向成熟导演的类型片项目
   - 需提交项目策划书、剧本大纲（中文或英文）

2. **青年导演项目**
   - 面向青年导演的首部或第二部长片项目
   - 需提交项目策划书、剧本大纲

3. **创作中项目**
   - 已开机或处于后期制作阶段的项目
   - 需提交20-45分钟初剪版本片花

### 申请要求
- 项目策划书、剧本大纲须提交中文或英文资料
- 完整剧本（如有）须提交

## 三、其他重要影展与创投会

### 1. 平遥国际电影展
- **时间**：通常每年10月
- **地点**：山西平遥
- **特点**：聚焦华语独立电影，设有创投会“平遥创投”

### 2. 中国独立影像展（CIFF）
- **时间**：通常每年11-12月
- **地点**：南京
- **特点**：关注独立电影、纪录片、实验电影

### 3. 金鸡百花电影节创投会
- **时间**：通常每年11月
- **地点**：厦门
- **特点**：官方背景，资源丰富

## 四、参与建议

### 对24帧品牌的启示
1. **项目储备**：如果有电影项目在开发阶段，可考虑参与FIRST创投会或SIFF创投会，寻求资金和资源支持。
2. **品牌曝光**：通过参与影展展映、论坛等活动，提升24帧品牌在行业内的知名度。
3. **行业连接**：影展期间的酒会、论坛是结识投资人、发行方、其他创作者的好机会。
4. **内容学习**：观摩入围影片，了解行业最新趋势和创作方向。

### 时间规划
- **已过截止日期**：FIRST创投会（3月31日）、FIRST主竞赛（4月28日）、FIRST超短片（5月31日）
- **即将到来**：上海国际电影节（6月）、FIRST影展（7月）
- **可提前准备**：平遥国际电影展（10月）、CIFF（11-12月）

### 注意事项
1. **报名费用**：不同板块报名费用不同，需提前规划预算。
2. **材料准备**：项目策划书、剧本大纲、片花等材料需提前准备。
3. **团队安排**：影展期间需安排主创人员到场，参与陈述、洽谈等活动。
4. **隐私保护**：提交材料时注意保护核心创意和商业信息。
