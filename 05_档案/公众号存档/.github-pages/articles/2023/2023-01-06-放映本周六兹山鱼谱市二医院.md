#  「放映」本周六 ·《兹山鱼谱》· 市二医院

**写在前面**  
我在这部电影中感受到了韩国电影的工匠精神，即使是从头到尾的单色影片，也能让人看得津津有味，因为真的是在扎扎实实讲故事，是在中国儒家的“入世”与道家的“出世”之间的矛盾与挣扎。  
这个故事很像苏轼，但苏轼要比丁若铨的一生更为戏剧化，仕途几经沉浮，博采儒释道三家思想，用无比宏大的心灵世界，成就一代文坛盟主。  
唯一的遗憾是这不是一部由中国人拍摄的电影，毕竟我们就有一个大名鼎鼎的苏东坡，可以拍摄的素材远超韩国。  
![](https://mmbiz.qpic.cn/mmbiz_jpg/E8dLbmPckyKAiae7ohJY29k3Ye0TJc49EZkR2DGhmtkrv50qZ3JsmIVlBNezxG3mFTZU2oOzS0Mt5DRnsC8K3iag/640?wx_fmt=jpeg)  
**放映员说**  
作为电影的外衣，其电影海报也很值得学习。海报一以贯之电影的黑白色调。当色彩被拿掉后，留给我们的是其它被放大  的  多重的美。  
「材质」  当去色后，画面所有元素的材质都开始凸显。我们更能从散乱的头发里捕捉风的质感，从粗布麻衣里感受朴素的味道，从海波礁石中得到力量的形状。  
「故事」  画面变得简单纯粹后，人物情绪就被放大。开怀大笑、悟道思索、满足对视都自然流露，感染力极强，也留给大家对故事更大想象的空间。  
「节奏」  在黑白之间，多重的灰层次应用，细腻又克制。在人与自然，构图与文字排版里，动与静也找到了最平衡的状态。
