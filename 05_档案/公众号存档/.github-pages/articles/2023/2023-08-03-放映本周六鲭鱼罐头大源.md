#  「放映」本周六 ·《鲭鱼罐头》· 大源

**写在前面**  
电影讲述了1986年长崎两个小学生的夏日冒险。  
透过鲭鱼罐头遥想那段在海上追逐的友情，唤起遗失的美好。  
《菊次郎的夏天》之后最美好的夏天必看电影，片中出现的弹珠汽水、筋肉人橡皮擦、当时正红的齐藤由贵，打闹的家庭日常……满满昭和元素是中青年观众的回忆杀。  
两个孩子的友谊背后是两个家庭和两段成长，从陌生到最好的朋友，或许是缘分在中作祟。被迫赴约的暑假冒险，却收获了人生最宝贵的东西。  
![](https://mmbiz.qpic.cn/mmbiz_jpg/E8dLbmPckyLsHdEa7s5mvicYkMksYV6SYBTR54BSJazUoKO5omkGuLaga5rdZlEthfLMbVtFHZ75BKXaPyxrk1w/640?wx_fmt=jpeg)  
**放映员说**  
大约是电影里的世界太美好，纯真的友谊，壮阔的大海，质朴有爱的人与人关系。太适合童年已经逝去的我们看了，在电影的某一刻我好像真的站在二十年前古老的太阳光下。  
那个夏天里，没人看见过海豚，甚至没人清楚回力镖岛究竟有没有海豚。我想只有童年才会有这样打动人的纯粹冒险，只是想出发，便出发了。  
两个小孩出发时爸爸推着自行车，放手时大喊着冲啊。我的眼泪瞬间喷出来。或许有人直到看到结束，使劲搜索也没法从脑子里搜刮出一丝可与之比拟的童年美好，我们从小受到的教育以及社会的鞭策，让我们变成了一个个出发前就在考量收获的人，我永远会被《鲭鱼罐头》这样的故事所打动，不是因为触动记忆力柔软的部分，或许是为了小时候只能看着别人玩的自己哭泣。  
下次见，一定要再见啊！：）
