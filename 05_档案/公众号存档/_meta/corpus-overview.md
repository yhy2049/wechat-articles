## 文章类型分类

### A. 放映预告/路演推文（约60%）
- 标题模式：「活动类型」+ 电影名 + 嘉宾/地点信息
- 核心结构：写在前面 → 放映员说 → 电影信息 → 报名/票价 → 社群 → 退票须知
- 子类型：新片专场、独立放映、成都路演、超前点映、告别场、返场、导演连线专场

### B. 回顾/记录类（约20%）
- 标题模式：「回顾」+ 活动名称 + 副标题
- 核心结构：活动概述 → 现场照片 → 观众反馈 → 策展团队署名
- 偏重：映后交流实录、影展回顾、年度总结

### C. 宣言/机制说明/招募类（约10%）
- 标题模式：关于/为什么 + 核心议题
- 核心结构：背景说明 → 变化原因 → 新规则/新方向 → 展望
- 偏重：品牌更名、退票机制、策展人招募、短片创作启动

### D. 影评/转载类（约10%，集中在2022年）
- 早期内容，多为合作作者投稿或转载
- 2023年后逐渐消失，被"放映员说"取代

## 风格演变阶段

### 第一阶段：初创期（2022.4 — 2022.12）
- 公众号名"少数派主义"，内容以转载影评+放映预告为主
- 结构简单：写在前面 + 放映信息 + 报名
- "放映员说"由主理人一人撰写，风格感性直白

### 第二阶段：成长期（2023.1 — 2023.12）
- 更名"24帧观影团"
- 放映预告标准化：写在前面 → 放映员说 → 票价 → 社群 → 退票须知
- 开始系统引入FIRST主动放映、戛纳短片展等影展品牌
- 退票须知固定为"票一经售出，除不可抗因素，恕不退票"

### 第三阶段：策展期（2024.1 — 2024.12）
- 团队扩展，文案/设计/排版分工署名开始出现
- "放映员说"不再仅由主理人撰写，出现多人署名
- 回顾类文章大幅增加，开始记录映后交流实录
- 海影节登岛回顾等长文出现（万字级）

### 第四阶段：转型期（2025.1 — 2026.5）
- 2025年底更名"24FRAMES PROJECT"，告别"观影团"
- 退票政策改为24小时可退
- 文风趋于内敛、沉稳，长句增多
- 策展人招募、短片创作启动，从放映组织向创作型组织转型
- 退票须知从"票一经售出...恕不退票"变为更人性化的注意事项列表

### 第五阶段：媒体化与创作并行（2026.5 — 2026.9）
- 影展前线报道成为主力内容形态：FIRST全景指南、评委会大奖专访（万字级问答体）、海影节报道
- 专访结构定型：采编信息块 → 影片简介 → 人物速览 → 分节问答 → 展映/获奖时间线
- 自有作品线启动：院线长片《浮生若丽》开机、演员招募、短片《弄死一条过》组讯
- 出现纯图片公告形态（封面即主视觉，正文仅梗概+话题标签）
- 组讯类短帖占比上升，作为招募与开机的对外通知渠道
