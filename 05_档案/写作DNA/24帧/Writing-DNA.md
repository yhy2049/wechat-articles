# Writing-DNA · 24帧公众号

> 读了277篇文章（2022.4—2026.5）之后捋出来的。写东西前看一遍够用。

---

## 语言特征

- **短句和长句换着用**。短句（≤20字）占将近四成——用来定调子、落情绪。长句（>50字）占两成——一般在"放映员说"里，一句一句往前推。
- **喜欢的句式**：拿问句开头（"一个男人将如何面对…"）；"不是…而是…" 这种先否定再递进；破折号用来岔开说点别的。
- **标点习惯**：空行多，读起来有换气的地方。感叹号很少，277篇里才190个。电影名必定用书名号《》括上。中文影展名有时候会夹英文缩写。
- **标题通常很长**：`「活动类型」电影名 · 副标题卖点 · 嘉宾` 一条标题塞进所有信息。

## 正文结构

**写活动预告/路演（最常见的类型）**：封面图 → 标题 → "写在前面"（两三句带入） → "放映员说"（核心部分，2到6段） → 时间地址票价 → 报名方式 → 社群引导（"扫码加好友拉你进影迷群一起交流"） → 注意事项。

**写回顾/活动记录**：封面 → 标题 → "写在前面" → 按环节分段（分1/2/3/4） → 中间穿插照片 → 末尾署名。

**写宣言/规则说明**：封面 → 标题 → 背景交代 → 分析（一句话一段） → 新方向 → 收尾。例子《为什么我们不再叫24帧观影团》。

**写影评**（主要在2022年）：传统影评结构。2023年以后不太写了，被"放映员说"代替。

## 写作视角

- **人称**：基本上用"我们"——团队视角。只有主理人本人说话时才用"我"。管读者叫"你"或"影迷"或"朋友"。
- **不说的词**："大家""本组织""观影团"这种太正式或太笼统的。
- **怎么建立信任**：把决策过程摊开来说——遇到什么矛盾、怎么处理的、数据多少都公开、署名谁做的。核心就一句话：你信任我，我回应你的信任。
- **24帧怎么想电影的**：电影不是看完就结束的东西。策展不是为了证明你懂电影，是让一群人能因为一部电影坐在一起聊起来。

## 选题排序

**优先找有主创到场的活动 > 影展获奖/入围的消息 > 能接上社会话题的 > 艺术/独立片 > 策展人自己提的。**

**素材从哪来**：先说自己为什么想看这部片 → 主创访谈里挖的料 → 影展口碑 → 社群的反应数据 → 专业的分析。

**不用的素材**：百度百科式的简介、豆瓣评分、导演履历堆砌、术语轰炸。

**切入角度**：从具体的人入手 → 用情感做底色 → 用理性做支撑 → 从一个小的点讲到大的事。

## 视觉

- 微信排版不用彩色字，加粗就够了。2025年以后间距更松了。
- 配图一般是文-图-文-图交替。宣言类的文章图片最少。
- 封面必须有。正文里用剧照、海报、人物照片、活动现场照片。文末固定放两个二维码：购票和社群。

## 风格怎么变的

2022年：口语化，感叹号多，标题短，结构简单。
2023-2024：影评味道重了，"放映员说"变成固定板块，"诚然""固然"这些连接词高频出现。
2025-2026：收着了。长句更密，短句独立成段变多，感叹号基本不用了。"或许""然而"变多了。

## 附：组讯/招募类文章的特殊声调

以上DNA主要基于放映预告、活动回顾、策展宣言等常规文章类型。从《浮生若丽》演员招募这篇文章来看，**组讯/招募类**文章在保留"我们"视角的同时，有一个显著不同的声调：

- **更坦诚的不确定性**。不装懂、不装稳。"说实话，作为联合制片方，又第一次做长片……最怕的是辜负了这份信任"——这种程度的示弱在预告类文章里不会出现。
- **"边走边看"的叙事节奏**。不是"我们做了这个决定"，而是"我们在做这件事，边学边做"。"今年年会我们夸下海口说要搞创作，磕磕绊绊拍了两部短片"——把来龙去脉摊开，不是炫耀，是交代。
- **用"差点意思"的句子收尾**。不追求金句感。"希望我们能更多探索创作，也能在这个过程中想起最初为什么会喜欢电影"——这句话不长不短，不重不轻，但比任何slogan都真。
- **核心套路**：先承认不足（"我们也不太会"）→ 说清楚在做什么（"这部片子讲的是…"）→ 坦诚条件（"预算很低"）→ 但这是真的（"能做喜欢的事情是不易"）→ 发出邀请。整篇读下来像一个人在对面说话，不是在念稿。
