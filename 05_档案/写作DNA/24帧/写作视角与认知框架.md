# 写作视角与认知框架

> L3-L5 分析产物。基于 277 篇公众号文章的选题逻辑、素材策略、认知框架和核心命题。

---

## 选题逻辑

### 选题来源（按重要性排序）

1. **电影排片驱动**（约占60%）
   - 院线新片上映 → 评估是否适合做专场
   - 影展获奖/入围片 → 快速跟进做放映
   - 经典重映/周年纪念 → 情怀驱动
   - 独立电影/艺术片 → 寻找差异化选片
   - 逻辑：先有电影，再有选题。不是"想写什么"，而是"想放什么"

2. **时间节点驱动**（约占20%）
   - 电影节档期：FIRST（五月）、戛纳（五月）、海影节（十二月）
   - 年度节点：年会、周年庆、新年、春节、封箱
   - 影片周年：上映X周年重映
   - 逻辑：用时间锚点制造仪式感

3. **组织变化驱动**（约占10%）
   - 品牌更名、退票政策调整、策展人招募、短片启动
   - 逻辑：需要向社群解释"为什么"

4. **社群共创驱动**（约占10%）
   - 影迷投稿、合作方提案、策展人自主策划
   - 逻辑：从"我策划→你来看"转向"我们一起做"

### 选题判断标准（隐式规则）

| 条件 | 选 | 不选 |
|------|----|------|
| 有主创到场（路演） | ✅ 优先级最高 | ❌ 普通排片 |
| 影展获奖/入围 | ✅ 强调荣誉背书 | ❌ 无奖项需另找角度 |
| 话题性/社会性 | ✅ 容易引发讨论 | ❌ 娱乐商业片除非经典 |
| 艺术片/独立片 | ✅ 社区调性匹配 | ❌ 主旋律/流量片除非有特殊角度 |
| 有策展人主动提案 | ✅ 鼓励共创 | ❌ 强行策划 |

### 选题角度策略

- **以人为本**：永远从人物切入（导演/演员/普通人），而非从概念
  - > "胡阿姨靠经营价格极其低廉的小旅馆为生…她用废弃垃圾建造了一个缤纷花园"
- **以情为底**：每个选题必须有情感锚点
  - > "如果是我自己买了票，我希望被怎样对待？"
- **以理为骨**：分析性段落提供理性支撑
  - > "荒诞诗学：伪纪录片下的真实震颤"
- **以小见大**：个人故事引向普遍主题
  - > "底层人的生活就是没有奇迹。影片的可贵在于它不刻意煽情"

## 素材策略

### 素材来源层级

| 层级 | 来源 | 使用方式 |
|------|------|----------|
| 第一层 | 个人观影体验 | "我是在看过第一遍后，回来听原声的过程中，喜欢上这部电影的" |
| 第二层 | 导演/主创访谈 | 路演现场实录、连线交流、VCR |
| 第三层 | 影展背书/获奖记录 | "#26SIFF金爵奖最佳纪录片"、"金椰奖最佳导演" |
| 第四层 | 影迷反馈/社群数据 | "我们收集了近百份影迷的私人十佳电影" |
| 第五层 | 电影专业分析 | 视听语言、叙事结构、符号解读 |

### 素材使用规范

1. **个人视角优先**：不说"这是一部好电影"，而说"我被这样打动"
2. **荣誉背书精准**：一句话带奖项全称和届数，不堆砌
3. **数据克制**：数据用在回顾和宣言类，放映预告几乎不用数据
4. **引用自然嵌入**：不单独引用块，引文融入叙述
5. **图片来源**：全部为微信公众号图片（mmbiz.qpic.cn），无外部图源

### 不使用的素材类型

- ❌ 百科式电影简介（除非极短）
- ❌ 第三方评分（豆瓣评分极少出现）
- ❌ 导演履历堆砌（只提及最相关作品）
- ❌ 行业术语轰炸（术语为分析服务，非展示）

## 认知框架

### 核心世界观

**电影不是看完就结束的东西。**

这个命题贯穿所有文章，构成24帧写作的思想基石：

- **电影作为关系媒介**：电影不是消费品，是人与人相遇的理由
  - "总有一部电影让我们相遇"
  - "我们不只可以呈现银幕上的故事，也可以将这份触动传递给更多人"
- **电影作为体验起点**：放映是开始，不是结束
  - "对我们来说，放映只是起点，策展、讨论和共创，才是事情继续发生的方式"
- **策展作为公共表达**：策展不是炫耀懂电影，而是创造交流现场
  - "策展并不是在证明你懂电影，而是把一次观看，变成一个可以被他人理解和回应的现场"

### 反复出现的几组对立

| 对立面 | 正面价值 | 负面价值 |
|--------|----------|----------|
| 观看 ← → 参与 | 共创、讨论、回响 | 被动消费、沉默 |
| 商业 ← → 独立 | 独立精神、作者表达 | 流量逻辑、讨好 |
| 宏大 ← → 微小 | 普通人、日常、韧性 | 宏大叙事 |
| 光亮 ← → 黑暗 | 银幕的光芒、聚在一起 | 散场、各自回家 |
| 理性 ← → 情感 | 被打动、触动、泪水 | 冰冷分析 |

### 价值观体系

**明确推崇的**：
- 独立精神、作者电影、艺术表达
- 社群共建、志愿者精神、策展人成长
- 对"小人物"的凝视与尊重
- 理想主义（即使它荒诞）
- 不确定性中的信任关系

**明确反对的**：
- 快餐式观影、屏摄、喧哗
- 流量驱动、仅以票房论英雄
- "打卡"心态、把电影当背景音
- 不散模式（低价免费→骗取方钱）

**隐含的前提**：
- 读者是"迷影"——懂一些电影语言，愿意花时间深度参与
- 读者生活在成都/川渝
- 读者相信"观影是有仪式感的事"

### 语调立场

- **第一人称复数**为主："我们"（团队/社群）
- **第一人称单数**为辅："我"（主理人个人视角，多用于机制说明）
- **称呼读者**为"你"、"影迷"、"观众"、"朋友"
  - "感谢你看到这里，我们就快互相抵达了"
  - "期待在'像素之外'与你相见"
- **不用"大家"** 作为称呼（过于笼统）
- **不用"本组织""我方"** 等官方用语

### 信任构建机制

1. **透明化决策**：解释规则背后的考量
   - "这个决定，其实并不是最近才发生的，只是最近，我们终于愿意把它说清楚"
2. **展示矛盾**：承认摇摆和犹豫
   - "有时候我会想，一张电影票，其实承载了挺多东西的"
3. **公开数据**：年度回顾中展示真实数据（48场放映、11场路演）
4. **署名开放**：从"主理人一人"到"策划/设计/文案/排版"多人署名
5. **信任回响叙事**：退票规则开放后，实际退票率不到5%

### 核心命题（可用于标题/金句）

- "电影不是看完就结束的东西"
- "总有一部电影让我们相遇"
- "把一个个策划想法变成现实"
- "感谢你看到这里，我们就快互相抵达了"
- "在下一帧开始之前"
- "光暗下来的时候，还有银幕会亮"
- "把电影从'被观看'，变成一件可以被讨论、被组织、被更多人参与的事情"
- "让观看变慢，让关系变深"
- "提问本身就是意义"
