# 文章结构模板

> L2 文章结构分析产物。基于 277 篇公众号文章（2022.4—2026.5，约84万字）。
> 文章按功能分为四种类型，每种类型有稳定的结构模板。

---

## 类型 A：放映预告/路演（约60%）

### 成熟期结构（2024—2026）

```
┌─ 封面图（电影海报/剧照，必填）
├─ 标题
├─ 写在前面（2-3句，引出电影/活动背景）
├─ 放映员说（核心影评段，3-6段，主观推荐）
│   ├─ 可选：用 `### 副标题` 分段（如"荒诞诗学：伪纪录片下的真实震颤"）
│   └─ 可选：用 **加粗** 提炼金句
├─ 预告片（可选，链接/视频号嵌入）
├─ 时间 / 地址 / 票价 / 报名方式
├─ 社群（"扫码加好友拉你进影迷群一起交流"）
└─ 注意事项（2025年后升级为详细列表）
```

**标题格式**：

```
「活动类型」电影名 · 副标题/卖点 · 嘉宾
```

- 活动类型：成都路演、超前点映、导演连线专场、联合放映、加场放映、独立放映、告别场、重映
- 副标题：影片核心卖点（影展入围/获奖/导演/演员/题材）
- 特征：信息密度极高，将卖点全部嵌入标题

**示例**：

> 「24帧导演连线专场」上影节最佳纪录片《胡阿姨的花园》在时代洪流中，守护一座花园，就是守护一个世界

> 「宇编三周年重映」现代西游：一部献给理想主义者的荒诞诗篇

### 早期结构（2022—2023）

```
┌─ 封面图
├─ 标题：「放映」本周六 ·《电影名》· 地点
├─ 写在前面（一段影评引入）
├─ 放映员说（一段，个人化推荐）
├─ 时间 / 地址 / 主持人
├─ 票价
├─ 社群（"扫码加好友拉你进影迷群一起交流"）
└─ 退票须知（"票一经售出，除不可抗因素，恕不退票"）
```

差异：标题更短、结构更简单、无预告片、退票须知为固定一句。

## 类型 B：回顾/记录类（约20%）

### 结构

```
┌─ 封面图
├─ 标题：回顾 | 活动名 + 副标题
├─ 写在前面（活动概述，时间、地点、参与人）
├─ 分环节记述（数字编号或标题分隔）
│   ├─ 1. 入场时刻
│   ├─ 2. 电影沙龙 / 大师班
│   ├─ 3. 短片展映
│   ├─ 4. 分享环节
│   └─ 5. 特别时刻
├─ 照片穿插（大量，每环节4-8张）
├─ 署名/致辞
└─ 未来预告/号召
```

**关键特征**：
- 第一人称团队视角（"24帧小分队""我们"）
- 个人化叙事，保留口语感（"靓靓"、"娜娜"）
- 大量现场照片穿插，每张配有简短说明
- 中后期回顾结构更丰富，分环节清晰；早期回顾偏简单

**标题示例**：

> 回顾6thHIIFF ｜2024海影节登岛一周：做自由而热烈的电影岛民

> 年会回顾 | 在下一帧开始之前，我们这样相聚

## 类型 C：宣言/机制说明/招募类（约10%）

### 结构

```
┌─ 封面图
├─ 标题：关于/为什么 + 核心议题
├─ 写在前面（或直接以"大家好，我是宇航员"开场）
├─ 背景说明（为什么做这件事）
├─ 具体分析（分点/分节）
│   ├─ 数据/事实支撑
│   ├─ 转折点描述
│   └─ 核心决策
├─ 新方向/新规则说明
└─ 展望/邀请/感谢
```

**关键特征**：
- 单句成段极为频繁，制造诗歌般的节奏
- "不是…而是…"否定递进句式高频
- 结尾常以"感谢你看到这里，我们就快互相抵达了"收束
- 语气从"我"的独白转向"我们"的集体叙事

**标题示例**：

> 为什么我们不再叫24帧观影团

> 关于我们为什么选择24小时退票

## 类型 D：影评/转载类（约10%，集中在2022年）

### 结构

```
┌─ 封面图
├─ 标题：诗意化标题
├─ 写在前面（电影简介）
├─ 正文（分段影评，数字编号或章节）
│   ├─ 一、主题分析
│   ├─ 二、叙事分析
│   └─ 三、结语
├─ 写在最后（个人感悟/金句引用）
├─ 参考来源
└─ 关注引导
```

**关键特征**：
- 2023年后逐渐消失，被"放映员说"替代
- 部分为转载/投稿，标注作者和来源
- 分析性更强，偏传统影评风格
- 2025年后偶尔有深度影评回归，但以"放映员说"板块呈现

## 通用结构组件

### 写在前面（187篇，67.5%）
- 功能：引导读者进入情境，提供背景或核心吸引力
- 长度：1-3段，短句为主
- 语气：从早期"朋友聊天"到后期"沉静邀请"

### 放映员说（152篇，54.9%）
- 功能：主观推荐，影评性议论，核心说服力
- 长度：2-6段，中长句为主
- 语气：个人化但有专业感，夹杂个人经历和影片分析
- 2025年后出现多作者署名

### 社群引导（189篇，68.2%）
- 固定话术："扫码加好友拉你进影迷群一起交流"
- 早期加"如果你也是做线下放映的也可以入群交（广）流（告）"
- 位置：报名信息之后、底部

### 注意事项（2025年升级）
- 早期：一句话"票一经售出，除不可抗因素，恕不退票"
- 2025年后：详细列表（入场签到、屏摄禁止、片尾不离场、迟到处理、退票规则）
- 2026年像素之外展增加了"影片可能会引发强烈情绪，请酌情参与"

## 段落节奏规律

| 元素 | 使用方式 |
|------|----------|
| 短句独立成段 | 宣言类中极频繁，每句一行，制造呼吸感和仪式感 |
| 长句展开议论 | 放映员说中，嵌套定语从句，层层递进 |
| 设问/反问 | 引出议题："一个男人将如何面对满目苍夷的人生？" |
| 排比/对仗 | "相遇了，相知了，牵手了，拥抱了，然后自自然然地说再见" |
| 破折号 | 补充说明、转折、强调，使用频率高 |
| "不是…而是…" | 否定递进，强调真实意图 |
| 数字分隔 | 回顾类用1/2/3/4编号，活动类用时间线 |
