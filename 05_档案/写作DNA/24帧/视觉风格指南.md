# 视觉风格指南

> L6 视觉风格分析产物。基于 277 篇公众号文章中的图片引用模式分析。
> 注：所有图片托管于微信服务器（mmbiz.qpic.cn），本地无独立图片文件。分析基于图片在文章中的位置、类型和功能推断。

---

## 配图策略

### 图片类型与频率

| 图片类型 | 出现频率 | 位置 | 功能 |
|----------|----------|------|------|
| 封面图 | 几乎每篇必填 | 文章顶部 | 吸引点击、定调 |
| 电影海报/剧照 | 高频 | 放映员说段落 | 展示影片视觉 |
| 导演/演员照片 | 中高频 | 路演/映后介绍 | 人物介绍 |
| 周边物料照片 | 中频 | 票价/报名区域 | 展示票根/海报/贴纸/冰箱贴 |
| 活动现场照片 | 中频 | 回顾类文章 | 记录现场，增强代入感 |
| 签到二维码 | 高频 | 报名区域 | 跳转购票链接 |
| 社群二维码 | 高频（181篇，65.3%） | 文章底部 | 引导加群 |
| 海报/宣发图 | 中频 | 品牌相关 | 活动主视觉 |
| 品牌logo | 低频 | 文章底部 | 品牌标识 |

### 封面图规则

- **格式**：顶部第一行，用 `![cover_image](url)` 标记
- **内容**：绝大多数为电影海报或剧照，少数为活动主视觉
- **风格**：偏艺术感，不选用刻意搞笑/夸张/商业海报
- **尺寸**：微信标准封面比例（2.35:1 或 1:1，微信自动适配）
- **2025年后**：开始出现自制活动海报作为封面

### 配图节奏

**放映预告类**：
```
封面图
↓
[文本 2-5段]
↓
剧照1（与放映员说内容对应）
↓
[文本 1-3段]
↓
剧照2（或海报）
↓
[报名信息]
↓
二维码（购票）
↓
社群二维码
```

**回顾类**：
```
封面图
↓
[开场文本]
↓
照片1-3张（活动全景/重要环节）
↓
[环节1文本]
↓
照片4-6张
↓
[环节2文本]
↓
照片7-10张
...
↓
收尾照片
```

**宣言类**：
```
封面图
↓
[文本，极少配图]
↓
[可能只有1-2张相关图片]
↓
[以文字为主，视觉克制]
```

### 照片选取原则

- **人物优先**：有人的照片优于无人的照片
- **真实感**：不修图、不过度滤镜，保留现场感
- **多样性**：远景/近景/特写交替
- **叙事性**：每张照片有"故事"，不是纯装饰
- **说明文字**：重要照片下方加简短说明（如"苏菲·玛索大师班：人生与银幕"）

## 排版格式

### 标题层级

| 层级 | 样式 | 使用场景 |
|------|------|----------|
| H1 | `# 标题` | 文章主标题，仅1个 |
| H2 | `## 标题` | 回顾类：大环节分隔 |
| H3 | `### 标题` | 放映员说中的小标题 |
| 无标记 | 加粗文本 | 板块标记（写在前面、放映员说、时间、地址） |

### 文本格式

| 格式 | 使用场景 | 示例 |
|------|----------|------|
| **加粗** | 板块标题、关键概念、电影名、票价、金句 | `**写在前面**`、`**￥35**` |
| `《》` | 所有电影名 | `《薄荷糖》`、`《爱乐之城》` |
| `「」` | 活动类型/品牌名 | `「放映」`、`「24帧」` |
| `""` | 引用/概念强调 | `"底层励志"`、`"手工制作"` |
| `｜` | 标题分隔符 | `回顾6thHIIFF ｜2024海影节登岛一周` |
| `▪︎` | 列表项标记（2025年后） | `▪︎现场签到领取周边` |
| `#` 空标题 | 视觉分隔（2025年后） | `##`（空行，用于制造间距） |

### 空行与间距

- **段间距**：文本段落之间留空行，每段2-3句
- **图片间距**：图片前后各留空行
- **单句成段**：宣言类中极频繁，每句之间空行
  ```
  三年多，我们放过院线电影，也放过独立电影和短片；

  做过单场放映，也做过围绕作者、主题、影展线索展开的策划。

  有些场次有导演来现场，

  有些导演来不了，我们就想办法连线，
  ```
- **2025年后**：间距更宽松，阅读节奏更慢

### 数字与标点规范

- **年份**：四位数字 `2022年` 或 `2022.4`
- **时间**：`19:30~21:30` 用波浪线连接起止时间
- **价格**：`￥30`、`￥35`、`￥45`，数字前加人民币符号
- **届数**：`第26届上海国际电影节` 或 `6thHIIFF`
- **序号**：回顾类用数字 `1`、`2`、`3` 单独成段

## 色彩与强调

### 微信平台限制下的色彩策略

由于微信公众号编辑器的格式限制，色彩应用非常克制：

- **色彩**：几乎不使用彩色文字，仅通过加粗实现强调
- **背景色**：不使用文字背景色/高亮
- **品牌色**：在活动主视觉海报中体现，正文中不体现
- **图片色彩**：由图片本身决定，不额外调整

### 强调体系

```
第一级：加粗（最重要）
  用于：板块标题、票价、金句、关键概念

第二级：书名号/引号（次重要）
  用于：电影名、概念引用

第三级：换行/空行（节奏强调）
  用于：制造停顿、引人注目

第四级：单句成段（最强强调）
  用于：宣言类中的核心命题
```

### 视觉密度

| 时期 | 密度 | 特征 |
|------|------|------|
| 2022 | 适中 | 图片间隔规则，文本密度均匀 |
| 2023-2024 | 较高 | 图片增多，信息板块丰富 |
| 2025-2026 | 稀疏 | 间距更大，呼吸感更强，图片精选 |

## 文字-图片协作

### 协作原则

1. **图片为文本服务**：图片不独立存在，必须配合文字说明
2. **文本为图片定调**：文字先于图片出现，图片作为佐证/延伸
3. **节奏交替**：文本→图片→文本→图片，形成视觉呼吸
4. **不靠图片填充**：图片数量与内容深度成正比，不滥竽充数

### 典型协作模式

**模式A：文本先行，图片佐证**
```
[文字描述胡阿姨的花园]
→ [胡阿姨花园照片]
[文字描述导演9年拍摄历程]
→ [导演照片]
```

**模式B：图片为主，文字点睛**
```
[回顾类：活动现场照片连排]
↓
[一句说明文字]
↓
[下一张照片]
```

**模式C：纯文字段落（宣言类）**
```
[无图，或仅1张]
[文字以单句成段排列]
[靠文字本身制造节奏]
```

### 二维码使用规范

- **购票二维码**：圆形/方形，通常为小程序码，放在报名区块
- **社群二维码**：固定在文章底部，带话术"扫码加好友拉你进影迷群一起交流"
- **数量**：每篇不超过2个二维码（购票+社群）
- **位置**：不遮挡正文，不浮动
