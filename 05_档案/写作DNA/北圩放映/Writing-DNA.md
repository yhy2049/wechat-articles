# 北圩放映 · Writing-DNA

> 整合版写作风格指南。写作前必读，快速查阅。

---

## 一、品牌定位

**北圩放映** —— 南京在地的非盈利影像交流社群（非俱乐部、非商业放映组织）。
- 启于 2022 年秋天的南京北圩路
- 由散步小李和阿狗联合发起
- 核心词：**独立 · 探索 · 多元**
- 标语：**「北圩放映，庆祝每一次相遇。」**

---

## 二、文章类型与结构速查

### 类型 A：电影放映推介（最常见）
```
开篇（感性与设问）→ 电影介绍（剧情+主题）→ 活动信息 → 映后指南（可选）→ 固定落款
```

### 类型 B：社群活动/夜话招募
```
观念引入 → 主题阐述 → 参与信息（时间/地点/费用）→ 分享者介绍 → 落款
```

### 类型 C：合作推广
```
北圩推荐 + 合作方名称 → 合作方内容转述 → 来源声明 → 落款
```

## 三、语言规则（必读）

### 开篇
- ✅ 使用反问/设问：「你是否也曾有过…？」
- ✅ 场景切入：「那一天特别闷热，闷到难以呼吸。」
- ✅ 社会观察：「当城市被算法切割成孤岛…」
- ❌ 避免开门见山直接罗列信息

### 语调
- 温暖、邀请式（「期待你来」而非「你应该来」）
- 真诚克制，不煽情、不营销
- 使用「我们」「朋友们」「伙伴们」
- 作者署名格式：**「原创 XX的」**（如「期盼夏日的」「伴你同行的」）

### 段落节奏
- 感性段 2-4 句，信息段用短行列表
- 关键句可独立成段
- 首段必带情绪/意象/设问

### 引文与引用
- 电影台词/简介：直接引用，引导性引入
- 导演评价：注明出处
- 学术引用：精确标注（作者、书名、出版社、页码）
- 合作方内容：标注「以下文章来源于XXX」

### 命名与标签
- 文章编号后缀：放映编号 / 夜话编号（如 056、060）
- 标题结构：编号 + 电影名 + 核心意象提炼
- 合作方标注：「北圩放映 x [合作方]」

## 四、必备元素清单

| 元素 | 说明 |
|------|------|
| 标题 | 编号 + 影片/主题 + 一句提炼 |
| 作者 | 「原创 XX的」+ 日期 + 地点 |
| 电影/主题介绍 | 剧情概要 + 主题分析（2-3段） |
| 活动信息 | 时间、地点、费用、报名方式 |
| 署名 | 「放映员：XXX」 |
| 落款简介 | 北圩放映由散步小李和阿狗联合发起…（固定模板） |
| 标语 | 「北圩放映，庆祝每一次相遇。」 |
| 配图 | 至少 2-3 张（剧照/海报/活动图） |

### 落款固定模板
```
北圩放映启于2022年秋天的南京北圩路，由散步小李和阿狗联合发起，是一个以非盈利影像交流为主的在地活动社群。
我们致力于营造一个公共场域，以「独立」、「探索」、「多元」为风向标，流动在南京的角落，在彼此的日常生活里融汇各类开放活动，联结更多志趣相投的同温层伙伴。
北圩放映，庆祝每一次相遇。
```

## 五、核心词汇库

### 必用词汇
- 空间：场域、角落、街头、流动
- 关系：联结、相遇、陪伴、同温层
- 感知：看见、听见、感受、回望
- 情感：温暖、真诚、柔软、轻盈
- 在地：南京地名（北圩路、南湖、莫愁湖、玄武湖、金鹰美术馆、四禧美术馆等）

### 避免词汇
- ❌ 营销感词汇：「限时」「错过不再」「爆款」
- ❌ 身份区分：「影迷」「粉丝」「会员」
- ❌ 商业术语：「GMV」「转化」「ROI」
- ❌ 居高临下：「教您」「你必须」「建议您」

## 六、结尾模式

### 活动邀约结尾
```
[日期]，我们在[地点]，
期待你来。

放映员：[名字]
```

### 感言式结尾
```
[主题]让我们[行动]，也让我们[结果]。
北圩放映，庆祝每一次相遇。
```

### 合作活动结尾
```
[合作方] × 北圩放映
[活动信息]

北圩放映启于2022年…
```
