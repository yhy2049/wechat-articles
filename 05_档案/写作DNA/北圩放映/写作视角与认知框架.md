# 北圩放映 · 写作视角与认知框架（L3-L5）

## L3 选题逻辑

### 选片标准
- **独立性优先**：非主流院线影片，独立电影、纪录片、短片为主
- **国际视野**：戛纳、柏林、威尼斯等电影节入围作品
- **在地关联**：能与南京本地文化/空间产生对话的影片
- **社会议题**：关注性别、家庭、教育、身份认同、边缘群体
- **女性视角**：女性导演作品、女性议题放映频率极高

### 活动类型谱系
```
北圩放映系列 → 标准放映活动（含映后交流）
北圩电影院系列 → 院线合作/超前点映
北圩夜话系列 → 圆桌讨论/社群交流
邻里柿系列 → 社区/公共空间项目
5分钟田野系列 → 短片试映/创作交流
特别策划系列 → 节日/主题特别活动
```

### 选题时机
- **节日驱动**：情人节、母亲节、七夕、冬至等节日策划
- **电影节驱动**：戛纳、柏林、威尼斯等电影节后跟进
- **合作方驱动**：与美术馆、书店、社区空间联合策划
- **社会议题呼应**：教育、性别、心理健康等热点话题

## L4 素材策略

### 首要素材来源
1. **电影本身**：剧情概要、导演介绍、获奖情况
2. **权威评价**：戛纳评审团颁奖词、电影节评语
3. **导演访谈/引言**：直接引用导演对作品的阐述
4. **学术引用**：本雅明、加缪、蒂姆·英戈尔德等
5. **合作方资料**：美术馆、书店提供的展品/活动介绍

### 引文使用规则
- 电影台词/简介 → 短引、直接引用
- 导演评价 → 引导性引用（「导演XXX评价」）
- 学术引用 → 精确标注出处（作者、书名、出版社、页码）
- 合作方内容 → 标注「以下文章来源于XXX」

### 图片素材
- 电影剧照（豆瓣来源）
- 活动照片（现场拍摄）
- 海报/设计图（合作方提供）
- 引用来源标注：「©XXX」「图片来自豆瓣」

## L5 认知框架

### 核心价值观
| 价值 | 编码方式 |
|------|----------|
| 独立性 | 「独立」「探索」「多元」三大风向标 |
| 非营利性 | 反复强调「非盈利」「公益交流」 |
| 在地性 | 扎根南京，使用本地地名、空间、机构 |
| 公共性 | 「营造公共场域」「在地营造良性公共场域」 |
| 联结性 | 人与人的联结、影像与社会的联结 |

### 核心假设
- **电影是媒介**：电影不仅是消费品，更是理解社会、建立关系的媒介
- **社群是方法**：通过观影活动构建社群，再通过社群延伸至更广泛的文化实践
- **在地即力量**：区别于全国性/线上社群，强调南京本地的独特性和优势
- **慢即是快**：拒绝急功近利，强调「缓慢的叙事节奏」「日常的碎片」

### 隐含的反对立场
- **反对商业化**：不打「不散」模式（免费观影写好评骗片方）
- **反对主流叙事**：不做「成功女性」「典型女性」的塑造
- **反对算法孤岛**：对抗「被算法切割成孤岛」的原子化社会
- **反对标签化**：反对「悲情叙事」「逆悲情叙事」「标签式抒情的写作」

### 社群哲学
```mermaid
graph LR
    A[观影] --> B[讨论]
    B --> C[情感联结]
    C --> D[社群形成]
    D --> E[在地实践]
    E --> F[更广泛的文化行动]
    F -.->|反馈循环| A
```

### 作者身份编码
- 「散步小李」：核心发起人，放映员身份，在电影和街道间散步
- 「阿狗」：联合发起人
- 自由撰稿人身份描述：前出版/编辑/学生 → 现为放映员（去权威化）
- 作者署名「XX的」格式（如「期盼夏日的」「伴你同行的」）—— 匿名化、场景化

### 自我定位
- 不是「俱乐部」或「影迷组织」
- 而是「非盈利影像交流为主的在地活动社群」
- 对标的是「在地社群」而非「商业放映机构」
- 自我认知谦逊，避免宏大叙事

### 语调原则
- **邀请式**：不说「你应该来」，说「期待你来」
- **平等式**：不说「我们教您」，说「一起」「共同」
- **开放式**：欢迎不同背景的人，没有门槛
- **克制式**：不煽情、不营销、不制造焦虑
