# 北圩放映 · 文章结构模板（L2）

> 基于文章类型分类的结构模式提取。

---

## 类型一：电影放映推介（核心类型，占多数）

### 典型结构

```
┌─ ❶ 标题行
│    北圩放映XXX｜电影名 + 核心意象/价值
│    原创 XX的 / 日期 / 江苏 / 北圩放映
│
├─ ❷ 感性开场（1-2段）
│    场景/意象切入 或 反问设问
│    → 建立情绪基调，引入电影主题
│
├─ ❸ 电影介绍（2-3段）
│    剧情概要（含豆瓣节选或导演引言）
│    主题分析（电影的社会/情感价值）
│    可引用原作评价、导演采访、获奖情况
│
├─ ❹ 活动信息（1段）
│    时间、地点、报名方式
│    「放映员：XXX」署名
│
├─ ❺ 映后漫游指南（可选）
│    周边推荐（咖啡厅、书店、夜市等）
│    步行路线
│
└─ ❻ 固定落款
     北圩放映简介（启于2022年秋天的南京北圩路…）
     北圩放映，庆祝每一次相遇。
```

### 实例对照

**文章**：北圩电影院 056｜重返青春游乐场,《去唱卡拉OK吧！》
- ❶ 标题 + 作者「期盼夏日的」+ 日期
- ❷ 「你是否也曾有过那样的年少时代？」开篇反问
- ❸ 漫画简介 + 剧情 + 主题分析（友谊、成长、青春阵痛）
- ❹ 活动信息（1月18日，南湖影城）+ 放映员署名
- ❺ 映后漫游指南（莫愁湖公园、南湖咖啡厅、夜市等步行推荐）
- ❻ 固定落款

**文章**：北圩电影院 053｜《如父如子》
- ❶ 标题 + 作者「爱不曾错位的」
- ❷ 「一次命运的错位…」场景切入
- ❸ 是枝裕和导演介绍 + 戛纳评审团奖颁奖词 + 主题分析
- ❹ 活动信息（12月7日，卢米埃）+ 放映员署名
- ❻ 固定落款

## 类型二：社群活动招募/夜话

### 典型结构

```
┌─ ❶ 标题行
│    北圩夜话XXX｜主题名｜参与者招募
│
├─ ❷ 观念引入（1-2段）
│    从社会现象切入，提出核心问题
│    「什么是『社群』？」式设问
│
├─ ❸ 活动说明
│    主题阐述（1-2段）
│    议题方向（Vol.01 子标题）
│
├─ ❹ 参与信息
│    时间｜地点｜费用｜人数
│    报名方式（链接/二维码）
│
├─ ❺ 特邀分享者介绍（可选）
│    个人简介 + 碎碎念（一段自我叙述）
│
├─ ❻ 活动呈现信息
│    主办方、策划、视觉、鸣谢
│
└─ ❼ 固定落款
```

### 实例

**文章**：北圩夜话060｜回到校园，回看「我们与社群的距离」
- ❶ 标题 + 作者「抛开书本上街去的」
- ❷ 「当城市被算法切割成孤岛…」引入
- ❸ 定义「社群」+ 活动主题阐述
- ❹ 时间（03/28周五晚19:00-21:30）｜地点（上海路地铁站附近·Ukelili）｜免费｜12人
- ❺ 两位分享者简介 + 碎碎念
- ❻ 主办方信息 + 策划编辑
- ❼ 固定落款

## 类型三：合作推广/联动内容

### 结构变体

- 开头：北圩推荐 + 合作方名称
- 正文：以合作方内容为主（转述或节选）
- 特点：标注「以下文章来源于XXX」来源声明
- 结尾：北圩放映简介（可能带合作方简介）

---

## 类型四：影评/回顾/试映

### 结构变体

- 以「试映短评」形式组织
- 多位作者对同一部/多部影片的短评集合
- 每条短评带署名（括号内）
- 例：「5分钟田野｜试映短评」中的多视角评论结构

---

## 通用结构规则

### 开头策略
- **感性优先**：极少直接罗列信息，必以情绪/场景/设问开头
- **第一句定调**：第一句决定全文情绪基调，通常是意象或反问
- **引语可用**：可用电影台词、原著引文、导演引言开头

### 中间节奏
- 感性段落（2-3段）→ 信息段落（2-3段）→ 感性收尾
- 信息密集处用列表/短行，避免大块文字

### 结尾模式
- 活动场次：以「XX月XX日，我们在XX，期待你来。」收束
- 招募场次：以「一起…」邀请式收束
- 固定落款：北圩放映简介 + 标语

### 落款格式（固定模板）
```
北圩放映启于2022年秋天的南京北圩路，由散步小李和阿狗联合发起，是一个以非盈利影像交流为主的在地活动社群。
我们致力于营造一个公共场域，以「独立」、「探索」、「多元」为风向标，流动在南京的角落，在彼此的日常生活里融汇各类开放活动，联结更多志趣相投的同温层伙伴。
北圩放映，庆祝每一次相遇。
```
