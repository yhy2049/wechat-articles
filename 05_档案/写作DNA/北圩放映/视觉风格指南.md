# 北圩放映 · 视觉风格指南（L6）

> ⚠️ **语料局限**：原始 PDF 中 60%+ 页面为图片（公众号页面截图），文本提取未能保留图像内容。以下视觉风格分析基于文章中保留的图片标注、排版描述和页面布局推断。

---

## 一、排版层级

### 微信公号排版体系
```
┌─ 标题行
│    [活动编号]｜[电影名/主题] + [价值提炼]
│
├─ 署名行
│    [作者构造] / [日期] / [地点]
│    北圩放映（品牌标识）
│
├─ 正文
│    感性段落（1-3段，带留白）
│    信息段落（活动信息）
│    固定落款
│
└─ 底部
│    阅读原文（链接）
│    推荐阅读（文章列表）
```

### 字体与间距
- 正文：中文宋体或系统默认字体（微信公众平台标准）
- 段落间距：2 倍行距或上下空行，视觉呼吸感
- 引文：独立段落，缩进或斜体

## 二、图片使用模式

### 图片类型
| 类型 | 用途 | 标注 |
|------|------|------|
| 电影剧照 | 核心文章配图，展示影片气质 | 标注来源 |
| 活动海报 | 活动宣传图 | 设计师署名 |
| 现场照片 | 活动回顾/花絮 | 摄影师署名 |
| 展品照片 | 合作展览/艺术空间介绍 | 合作方提供 |
| 地图/路线图 | 映后漫游指南 | — |
| 左滑图集 | 多图展示（左右滑动查看） | 左滑指示 |

### 图片置入节奏
- 感性段落之间：1-2 张电影剧照
- 信息段落中：1 张海报或活动图
- 片单/影片介绍：每部影片 1 张海报或概念图
- 合作方内容：合作方提供的展览/活动图

### 图片来源标注
- 「©四禧美术馆」
- 「图片来自豆瓣」
- 「©摄影师名称」
- 「图片编辑：XXX」

## 三、特殊元素

### 滑动图集指示
- 「左右滑动，查看详细片单」—— 常见于片单展示
- 「左滑看看大家怎么坐」—— 社区活动展示
- 「左右滑动，查看往期试映」—— 回顾展示

### 分隔与装饰
- 「——」作为主题段落间的分隔
- 活动信息用短横排列（时间｜地点｜费用）
- 编号用 01、02、03 二级标题
- 方括号「★」标记重点信息

### 排版密度
- 感性段落：稀疏排版
- 信息段落：密集排版（片单、日程、价格）
- 整体：中低密度，大量留白

---

## 四、品牌视觉元素

### 品牌名
- 「北圩放映」：固定显示在文章开头和底部
- 名称中的「北圩」：南京北圩路，地名文化锚点

### 品牌标语
- 「北圩放映，庆祝每一次相遇。」—— 每次文章底部必出现
- 风格：短句、温暖、非商业

### 签名
- 「放映员：散步小李」—— 每篇文章结尾的署名
- 「放映员：小朱」—— 偶尔轮换

### 活动信息视觉
- 核心活动信息（时间、地点、费用）以**短行列表**呈现
- 关键动词用符号前缀（★ 标记重点）
- 名词和地点用「」强调

## 六、缺失信息（图像源限制）
以下视觉元素因语料为 PDF 截图未能获取：色调偏好、字体字号精确值、色彩模式、logo 设计、emoji 使用习惯、图文比例精确值。如需完整视觉分析，建议提供微信公众号原文链接或原始公众号文章。实际文章是公众号推送，包含完整的富文本排版和图片。因此推断该账号使用的是**微信公众号默认排版 + 适度自定义（段落间距、引用、图片插入）**，并不依赖复杂排版工具。

## 七、写作时视觉参考建议

1. **图片优先**：每篇文章至少 2-3 张配图，优先使用电影剧照和活动海报
2. **「左滑」功能**：多图时使用左右滑动组件
3. **留白充足**：段落间空行，避免文字块过于密集
4. **引语独立**：关键引言独立成段
5. **短行列表**：活动信息用短行而非段落
6. **底部常量**：固定落款（简介 + 标语）
