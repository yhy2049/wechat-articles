# 24FRAMES PROJECT（24帧）媒体介绍资料

## 一、媒体定位

**24FRAMES PROJECT（24帧）** 是一个根植于成都的独立电影放映与影迷社群品牌，成立于2022年。

品牌名取自电影的基本单位——每秒24帧画面。我们的核心使命是让好电影被看见，让看电影的人被理解。

我们不是传统意义上的电影媒体或影评平台。我们的角色更接近"电影现场的组织者与传播者"——以放映为起点，通过策展、映后交流、社群运营与内容创作，把"看电影"从一次消费行为，延展成一种持续的文化参与。

**一句话定位：** 为那些在电影里寻找共鸣的人而存在的放映社群与文化媒体。

## 二、运营内容

### 2.1 放映与策展

四年累计超过 **220 场放映**，覆盖以下形态：

- **常规/主题放映**：按导演、类型、情绪策划系列放映，形成稳定的内容节奏
- **新片点映与城市路演**：组织主创到场/连线的点映场次，提供映后深度交流
- **周年独立放映**：每年举办品牌周年特别放映，选片聚焦独立电影与小众佳作
- **影展策展**：承接影展地方站策展与执行，如 FIRST 主动放映成都站

### 2.2 映后交流

电影放映结束后组织现场交流是 24帧 的核心传统。形式包括：

- 导演/制片人现场映后
- 线上连线映后（导演、影评人、行业嘉宾）
- 主题沙龙与对谈

我们认为电影不是看完就结束的事情，映后交流是让一次观影沉淀为公共讨论的关键环节。

### 2.3 短片创作

2026年启动短片创作方向，利用社群资源与策展经验，为年轻创作者提供从创意到成片的协作平台。首部短片预计 2026 年下半年发布。

### 2.4 内容出品

公众号持续产出原创内容包括：

- 影片评论与深度解读
- 放映活动预告与回顾
- 影展专题报道
- 城市电影文化观察

累计发布 **118 篇原创内容**，多篇阅读量破千

### 2.5 电影节现场报道

24帧 曾三次以媒体身份受邀参与国内电影节现场报道：

- **第六届海南岛国际电影节（2024）**：小分队赴三亚全程参与，持媒体证报道金椰奖竞赛、大师班、产业论坛、海边放映等环节，产出多篇专题回顾
- **第七届海南岛国际电影节（2025）**：再次以特邀媒体身份登岛，深度报道影展内容与行业观察
- **HiShorts! 短片周（2025）**：赴南宁报道短片影展，与创作者深度交流并产出主题回顾文章

三次电影节现场经历，印证了 24帧 具备独立的电影节报道能力与内容产出效率。

## 四、与 FIRST 的合作基础

24帧 与 FIRST 青年电影展已有长期的深度合作：

- **2023 年**：承办 FIRST 主动放映成都站「附近的消逝」
- **2024 年**：持续承办 FIRST 主动放映成都站
- **2025 年**：承办 FIRST 主动放映成都站「衔尾蛇」—— 三天展映 16 部影片，吸引 137 位现场观众，多场导演映后连线交流
- **2026 年**：承办 FIRST 主动放映成都站「Freaky boom——直到长出毛边」，单篇推送阅读量 1,067，为年度阅读量最高文章

四年连续落地 FIRST 主动放映，24帧 已成为 FIRST 在成都最稳定的合作放映伙伴。

## 五、申请媒体注册的理由

作为连续四年承接 FIRST 主动放映成都站的本地放映组织，24帧 与 FIRST 之间已经建立了长期信任与协作默契。我们希望通过申请媒体注册嘉宾，在今年的影展期间实现以下目标：

- **内容传播**：以本地媒体身份对 FIRST 入围作品进行深度报道与评论，将电影节内容更完整地带回成都社群
- **现场记录**：报道影展现场、映后交流、行业论坛等环节，产出高质量的图文内容
- **社群连接**：将影展的核心精神与优质内容，通过24帧的渠道矩阵传递给成都影迷

我们相信，24帧 是 FIRST 在成都本地最懂独立电影、最能连接真实观众的社群出口。连续四年落地的主动放映，已经证明了双方协作的稳定性与执行力。
