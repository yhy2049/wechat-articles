# 24FRAMES PROJECT（24帧）报道计划与采访需求

## 一、报道计划概述

24帧 将以"到场者"的个人视角参与本届 FIRST 青年电影展。考虑到本次以单人形式前往，报道策略聚焦于**一篇深度内容 + 多篇轻量输出**，在保证内容质量的同时，确保报道节奏的可持续性。

**报道原则：**
- 以个人视角记录现场体验，像写给朋友看的日记，而非机构化的通稿式报道
- 聚焦创作者故事与现场瞬间，呈现电影节作为"人与人相遇的空间"
- 深度内容追求质量，轻量内容追求频次，两者配合形成完整的报道节奏

## 三、24帧的独特优势

1. **连续四年 FIRST 主动放映承办方**：对 FIRST 生态的深度理解，能够从"合作者"而非"旁观者"视角进行报道
2. **三次电影节现场报道经验**：海南岛国际电影节（2024、2025）、HiShorts! 短片周（2025），具备成熟的现场报道流程与内容产出能力
3. **成都本地社群连接**：公众号关注超过 11,000 人，活跃影迷社群，能够将 FIRST 内容精准触达本地独立电影受众
4. **"报道→放映→社群讨论"的闭环能力**：24帧不是来报道完就回家的媒体——我们能把好片子带回成都，办一场放映，再写一篇映后。这个链条跑通了就是完整的内容生态，这是其他报道媒体做不到的

## 四、采访需求

### 4.1 拟采访对象

| 类别 | 拟采访对象 | 采访形式 | 优先级 |
|------|-----------|----------|--------|
| **主竞赛入围导演** | 1-2位，优先选择首作或具有独特创作视角的青年导演 | 现场专访（15-30分钟） | 高 |
| **FIRST FRAME 入围导演** | 1位，聚焦女性创作者视角 | 现场专访或线上连线 | 中 |
| **观众/志愿者** | 随机采访2-3位，记录"从观众角度看FIRST" | 现场随机采访 | 低 |

### 4.2 采访方向与核心问题

**导演专访方向：**
- 创作起源：这部作品的种子是什么时候、以什么方式种下的？
- 语言探索：在寻找属于自己的影像语言过程中，经历了什么？
- 青年导演的处境：创作资源、表达自由、市场压力之间的平衡
- 对"FIRST"这个平台的理解：它对青年创作者意味着什么？
- **你这部片子如果只给一个人看，想给谁看到？**（不是"希望谁看到"，而是具体到一个人）
- **拍完这部之后，你之前相信的关于电影的事情，有哪件变了？**

### 4.3 采访资源需求

| 需求项 | 说明 |
|--------|------|
| 媒体专访通道 | 希望获得影展期间的媒体专访通道，以便安排导演专访 |
| 排片优先权 | 重点场次的提前排片信息，便于规划采访与报道节奏 |
| 现场拍摄许可 | 影展现场、放映厅、映后活动等区域的拍摄许可 |
| 媒体资料包 | 入围影片资料、导演介绍、高清剧照等素材支持 |
