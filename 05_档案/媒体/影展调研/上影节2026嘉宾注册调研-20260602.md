## 一、第28届上海国际电影节基本信息

- **举办时间**：2026年6月12日 - 6月21日（共10天）
- **举办地点**：上海
- **金爵奖评委会主席**：梁朝伟
- **第31届上海电视节**：6月22日 - 6月26日

## 二、注册通道状态

### ❌ 产业嘉宾注册（已截止）

| 项目 | 详情 |
|------|------|
| 截止日期 | **2026年5月31日**（已过2天） |
| 注册费用 | 早鸟 1,280元/人 → 标准 1,800元/人（产业嘉宾A） |
| | 早鸟 880元/人 → 标准 1,200元/人（产业嘉宾B） |

| 权益B | 可参加市场活动、论坛、工作坊、资料包 |

### ✅ 媒体记者注册（仍开放至6月7日）

- **截止日期**：2026年6月7日
- 需持有国家主管部门核发的记者证
- 每家媒体限2名文字+2名摄影
- 可通过 siff.com → 注册·申报 → 记者注册 通道申请

### ❓ 其他入场方式

- 普通观众可通过展映购票参与（排片表尚未公布）
- 部分论坛/活动可能开放公众预约（需关注官方渠道后续公告）

## 三、注册流程（已完成参考）

1. 登录 siff.com → "注册·申报" → "来宾注册"
2. 选择来宾类型（产业嘉宾A/B）
3. 填写资料并递交申请
4. 组委会审核资质（通过后收到邮件）
5. 完成缴费
6. 收到确认函，获取来宾证件

## 四、联系方式

- 注册中心电话：+86-021-62808991
- 邮箱：guest@siff.com / guest@stvf.com
- 官方微信公众号：上海国际电影节（ID: SIFFinShanghai）

## 五、行动建议

1. **立即联系组委会**：致电注册中心或发邮件给 guest@siff.com，询问是否可补注册（仅过2天，或有宽限）
2. **备选方案：以媒体身份注册**：如果用户有媒体渠道，记者注册通道开放至6月7日，还有5天时间
3. **关注后续开放通知**：部分论坛/工作坊/创投公开陈述可能在临近时开放额外登记
4. **作为普通观众参加**：展映购票仍可参与电影节，但无法参与产业活动
