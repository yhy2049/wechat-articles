> ⚠️ 必须凭**纸质票**入场，不支持电子票。仅限在观影影院专用取票机取票，**不支持跨影院取票**。建议提前1小时到达取票。

### 硬规则
- **不退不改不换**：全部场次不支持退票和改签
- **限购**：同一用户单场至多4—6张
- **无儿童票**：一人一票，对号入座
- **不可用券**：不支持代金券、兑换券、88VIP、影城卡、观影金等
- **多笔订单规则**：账户同时只能有一笔待支付订单。新下单会自动取消前一笔未付订单并释放座位。

### 支付与福利
- **云闪付**：大麦9.0.20+ / 淘票票11.16.1+ 支持云闪付付款，享**立减优惠**
- **浦发银行+银联双重购票福利**（限量）
- **滴滴**：App搜「上海国际电影节」，领最高100元打车券包（每14天可领一次）
- **携程**：6月5日—17日选购指定产品，单笔订单可兑一张电影票（单人最多5张），累计3单加赠限定周边
- **美团**：6月12日—21日领酒吧/KTV专属优惠，持票根兑换礼品
- **会员积分**：正常计入淘麦VIP，单笔上限300分，单日上限500分

### 放映规模
- 420+部影片，1500+场次，52家影院（覆盖上海16区+五个新城）

## 四、抢票策略建议（实操版）

### 1. 开票前（6月4日—6月5日12:00前）
- [ ] 提前下载 **大麦App / 淘票票App**，确认账号正常、实名认证已通过
- [ ] **决定主攻平台**：大麦和淘票票的「日程」不互通，选定一个作为主力
- [ ] 浏览排片表，标注必看和备选影片
- [ ] **利用「+」加入日程功能**：在排片列表右侧点击「+」，将心仪场次提前加入「我的日程」。开售后可直接从日程一键下单（省去搜索时间）
- [ ] 用个人表格做第二层备选：每部热门片准备 **2—3个备选时段/影院**
- [ ] 绑定云闪付，确认大麦/淘票票版本满足要求
- [ ] 领取滴滴打车券包（可提前领）

### 2. 开票日（6月5日）
- [ ] **12:00准时**开抢，提前5分钟进入App上影节专题页
- [ ] 优先从「我的日程」一键购票（比从头翻排片快得多）
- [ ] **抢片顺序**：大师专题（怀尔德/洛奇/瓦伊达/塔尔/怀斯曼）> IMAX/杜比特映 > 热门华语竞赛片 > 其他
- [ ] 抢不到立刻切备用时段，不要犹豫
- [ ] 每张票只买一种，不要等拼多份再付款——单次只开一个订单窗口
- [ ] 14:00线下窗口开售（部分影院可能有预留票）

### 3. 首轮失手后的补救
- [ ] 持续刷新：开票后常有**出票失败释放的座位**回流
- [ ] 延长放映（6月22日—28日·5家影院）届时会另行售票
- [ ] 同步关注淘票票渠道，两平台库存不一定完全一致

### 4. 作为注册嘉宾/产业嘉宾的便利
留意嘉宾注册邮箱是否有专属通道或优先预约通知。
