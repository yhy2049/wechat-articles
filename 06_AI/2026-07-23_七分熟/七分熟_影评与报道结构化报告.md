## 一、核心报道来源

### 1. 凹凸镜DOC — 深度导演访谈（完整版）

**标题**：《七分熟》：用纪录的方式拍剧情片，一次中女电影的影像实验
**发布平台**：微信公众号「凹凸镜DOC」（同步发布于网易号、澎湃新闻）
**类型**：深度导演访谈（Q&A 形式，涵盖16个问题，逾万字）
**核心观点**：

| 议题 | 导演表述要点 |
|------|-------------|
| **创作动机** | 博士毕业时面临大学教职 vs 让孩子在大理接受教育的两难，长达半年的焦灼状态转化为创作动力 |
| **片名"七分熟"** | 相对论式概念——全力以赴做的事，一两年后回看可能只有七分，但当时仍会用尽全力；英文名 Gold Life 意味着"不完美但已是黄金生活" |
| **真实与虚构边界** | 遵循三幕剧框架，虚构部分是对未来的"预演"；真实人物（母亲、继父、五姨、外婆、朋友）全部出演 |
| **核心矛盾** | 一个极具主体性的女性，进入婚姻和生育后仍面临重重困难，追问"为什么依然深陷困境" |
| **女性视角** | 不刻意规避或强化，天然就是女性视角；希望观众把影片当作"一个人"的故事来看待 |
| **拍摄方法论** | 拿大纲拍，没有完整对话稿；每场戏确定一句核心台词，其余即兴；小孩戏完全不讲戏直接抓拍 |
| **醉酒戏** | 真实喝断片，剧组自发完成拍摄；孩子说"我都困了"比说"我爱你"更珍贵 |
| **预算与团队** | 线下30万现金，12人团队，索尼FX3/FX6拍摄，辗转大理/昆明/四川邻水三地 |
| **反权力结构工作方式** | 有问题不追问部门，亲自带头解决；剧组三天后形成自组织协作 |
| **"女性导演"标签** | 不会应激反对，但希望观众将影片看作"一个人"的故事，这是女性主义的重要进步 |
| **下一部作品** | 仍聚焦家庭剧情，大概率以女性叙事为主 |

**评价角度**：
- 凹凸镜DOC以**纪录片/独立影像媒体**视角切入，关注影片的"真实与虚构"实验、低成本制作方法论、以及女性议题的社会公共讨论价值
- 访谈风格专业、深入，从创作动机到制作细节到社会议题逐层展开

### 2. 深焦DeepFocus × 苏七七 — 导演创作访谈

**标题**：一个母亲，一个女儿，决定成为一个导演——《七分熟》导演张歆访谈
**发布平台**：微信公众号「深焦DeepFocus」/ 豆瓣
**访谈人**：苏七七（影评人、导演，作品《长谈》入围南特三大洲电影节）
**类型**：女性创作者之间的对话（深度对谈，不同于传统Q&A）

**核心观点**：

| 议题 | 对话要点 |
|------|---------|
| **创作喷发** | 2023年在大理，制片人泥巴和木卫二来大理，看到她带孩子和想创作之间的冲突，决定做这个片子 |
| **剧本启动** | 一天写完大纲，星期三开始招募剧组，启动极快，"久被压抑的表达欲的喷发" |
| **第一性意识** | 从小自然认为自己是第一性，父亲早逝，母亲从小教育"一定要独立，不能依靠任何男人" |
| **导演身份作为工具** | 做电影不仅是表达，也是解决困境的方法——"拿到一个导演的身份" |
| **真实的空间** | 酒吧、咖啡店、家都是真实场景，只有外婆家借了邻居的房子（同户型） |
| **纪录×剧情** | 纪录片没有绝对真实，剧情片也未必不真实；"真实不在纪录与剧情之分野，而在所表达的东西与生活、社会、真理的关系" |
| **伦理问题** | 正视"是否在利用和贩卖私人经验"的追问；最后一场戏让所有工作人员出镜，打破第四堵墙 |
| **母爱与母职** | 母爱是身体的天然，母职是责任；孩子挂件般的沉重感，妈妈群体看后都哭了 |
| **人物塑造** | 刻意不往容易被共情的方向塑造，而是"往不被共情、不被认可的方向推"——一个抽烟、喝酒、有野心和欲望的嬉皮母亲 |
| **七分熟哲学** | "当下这一刻是我人生中最成熟的，做出的所有决定是当下最正当的；哪怕人生永远只有七分熟，当下一定要用最大的力气去活" |
| **制作细节** | 12人团队，索尼FX3/FX6，曾用iPhone 15 Pro Max拍了一场戏；线下30万，加后期全线上百 |
| **观影体验** | 苏七七评价："感同身受之处极多……那种作为女儿、作为妈妈、作为自己，都总在内疚、自我怀疑的感觉，是一样的" |

**评价角度**：
- 深焦以**女性创作者/迷影文化**视角切入，强调"女性创作者之间的彼此辨认与追问"
- 苏七七作为同样从女性经验出发创作的导演，访谈更具个人共鸣和情感深度
- 关注点：纪录与剧情的方法论、女性主体性、母爱与母职的张力、自我袒露的勇气

## 四、关键信息汇总

**影片基本信息**：
- 片名：七分熟 / Gold Life
- 导演：张歆（北电博士，自编自导自演）
- 入围：第20届FIRST青年电影展主竞赛单元（获"最佳剧情长片"提名）
- 首映：2026年7月19日
- 时长：未公开具体时长
- 制片地区：中国
- 格式：彩色，剧情片
- 语言：普通话、四川话

**制作关键数据**：
- 拍摄周期：2024年9月（一周）+ 10月中旬（20天）
- 团队规模：不超过12人
- 线下成本：约30万现金（含后期总成本上百）
- 拍摄设备：索尼FX3/FX6（主）、Sony A7m3、iPhone 15 Pro Max、DV
- 拍摄地点：大理、昆明、四川邻水
- 声乐：花西乐队配乐，剪辑指导汪迪

**叙事核心**：
- 女主人公章昕（张歆饰），大理生活的女博士，与丈夫分居、和母亲冷战
- 全职带儿子，同时挣扎于事业和自我实现
- 剧情大纲拍摄，大量即兴
- 真实人物（母亲、儿子、五姨、外婆等）全部出演
- 最后一场醉酒戏为真实喝醉后即兴完成

**性别议题立场**：
- 导演天然以"第一性"处理女性角色
- 希望超越两性议题，让男性观众也能看到中年处境
- 认为"女性导演"标签是社会分类方式，不会应激反对
- 希望观众将影片视为"一个人"的故事
