# FIRST 影展采访（口癖清理版）

受访：24帧 宇航员 
采访：B站频道“绝对影感BeingAmateur”运营人葛阳 
2026年7月23日｜西宁

---

**Q：可以先简单介绍一下自己吗？**

大家好，我叫宇航员，是成都独立放映组织“24帧”的负责人。这是我第一次来到电影节的现场，参加相关活动。

**Q：是什么样的契机把您带到了 FIRST 影展？**

今年我离职了，所以想多看一下电影节。FIRST 又是这种青年创作者的平台，刚好有很多认识网友今年也来到了现场，想和大家有一次见面的机会，同时想看更多好看的片子。有机会的话，我们可以带到成都继续做放映。

**Q：目前来看，您对 FIRST 之旅的感受是什么样的？**

和之前我对 FIRST 的理解不太一样。之前因为大多数是看获奖后的片子，会整体认为 FIRST 的片子水准比较高。但这次因为看了所有的入围作品，过程中让我感觉到作品层次是不齐的。好的片子拍案叫绝，稍微没有那么好的片子，会感觉到非常强烈的学生作品以及粗粝的感觉。

**Q：有没有什么特别喜欢的电影可以推荐给观众？**

我喜欢的一部是《河以为家》。这也是我在所有片子里面唯一打了五星的片子。这部片子我很喜欢，喜欢的原因很简单——它用三段式的表达和剪辑，切得非常好，包括整个片子的叙事感、冲突以及它的笑点分布，还有最后的一个升华，我觉得做得都挺好的。

这个片子开始我会以为是一个关于环境保护、维权的纪录片，但到后面发现它视角落在了具体的人物身上，让我们看到了非常伟大的女性力量，这是这个片子中很好的一个亮点。

**Q：在故事片层面，有没有觉得还可以的作品？**

故事片的话，我比较喜欢的是《七分熟》和《地下美人》。

《七分熟》首先是导演整个拍摄的虚实结构或者说节奏，我觉得非常舒服。同时关于女性的职场困境以及家庭的平衡关系，能够让观众瞬间带入。里面导演有去设定的几个泪点，全场观众也能够迅速地去带入情绪，这是这个电影做得比较好的一面。

《地下美人》是一个非常好的工业化电影，无论是摄影还是选角，以及角色的演出，我觉得都是非常精良的，是适合大银幕的电影。

**Q：说到工业化，今天在《七分熟》展映后，主持人作为初评审之一说了一句话——现在制作上很好的电影已经很多了，所以他们在选片时会更倾向于文本。您觉得对于一部电影来说，是制作画面更重要，还是文本更重要？**

我觉得文本很重要，画面我倒不觉得它非常重要。拿今年的一部片子来做类比的话，比如《河以为家》，它是一个纯手机来拍摄的纪录片，但是大家更喜欢的是它的叙事以及它的剪辑。导演跟踪了时间也蛮久了，但是如何去剪出一条人物线，如何在线索中去再立出你的编剧思维，这对一个导演能力的考核会更高。

画面好的片子会有很多，但是能有很好编排思路的导演其实是比较少的，所以这也是我比较看重文本、选角、台词以及核心输出的原因。

**Q：FIRST 的片子很多有一个共同的问题——它们如果剪成短片会更讨喜，但做成长片就显得有些撑？**

对。FIRST 的片子大多数会有一个通病——明明是一个很小的核心观念，但它塞入了很多角色和文本，让它填充成一部长片。看的过程中可能某一个点或者说核心的那场戏让你产生触动，但是整个片子看下来会比较乏味。

**Q：今年的展映影片中，有没有让你不太满意的？**

不太满意的长片是《我的心是旷野的鸟》。这个片子它的故事是个很好的故事，讲的是女性意识。但是比较遗憾的是选角以及人物的表演情绪——导演想要把它表达出来，但是角色在演绎的过程中没有产生这样的爆发力，所以整个片子看起来有点"发生可成"。

短片整体还是不错的，其他更多的片子都算中规中矩吧。

**Q：有一种评价说，超短片在调度的复杂性、光影设计的复杂性、工业制作的完成度上可能比今天的短片还要高，您怎么看？**

确实。超短片情绪给得非常足，我也看到了很多制作特别精良的超短片，从布景、光影到摄影以及人物情绪设计，我觉得都非常好，这方面确实比有些短片做得更好。

但是超短片也会出现一些问题——有点偏宣传片，或者说是 TVC 广告，没有短片那种叙事结构，更多是为了情绪的爆发而做，而不是在叙事节奏上下功夫。

**Q：从整体选片角度，您有什么建议吗？**

选片整体还是不错的，短片我觉得没有太大问题。但是长片上可能还是要更多地去考量——如果说这个片子它更适合短片，或者剪出来短片能力更强的话，它不应该在长片去做入围。

另外短片有些分类可能有些问题。有些片子我会认为它更适合去先锋，有些片子不太适合它现在的单元。虽然说是女性作为了这个主体，但是它的整个叙事和焦点其实是没有放在女性的视角上。分类如果更精准，观众在看的时候不至于产生一些错误的评价。有些片子如果去到先锋，大家可能会觉得是一个不错的片子，但它恰恰出现在了真人短片单元，就会让观众觉得这个片子有点"云里雾里"，甚至觉得是自己的艺术造诣不够。

**Q：近年 FIRST 有一个争议——《探子必须死》那部片子很多人觉得拍得特别烂。但导演说过一句话，他说自己是北京人，所以不想去拍乡村题材或者敏感地区的题材去取巧，北京人就拍北京的故事。您怎么看待现在独立影展中，一些出身一线城市的创作者为了取巧，去讲一些和自己生活不相关的故事？**

我在短片中也发现了有这样的片子。一个好的故事被拍成了一部烂片，或者说一首好诗，然后根据这首诗来创作了一个影像，但给我的感觉是影像没有意义——诗本身更打动我，但变成了一首在影像中的诗，虽然伴随着画面，但我觉得不够，没有文字给我的力量更直接。影像介入的过程中，我认为它没有去放大文字的力量。影像如果不能放大好的故事，那影像依然没有意义。

所以我能够理解你说的——大家去拍摄一些与自己经历无关的片子，然后为了获奖。但观众有自己的审美判断，因为大家不是为了听一个好的故事，而是希望影像能让自己亲身经历了这样的一个场景，产生和作者也好、和主人公也好类似的心境。

确实大家还是得想一想怎么去捕捉好的故事并且把它呈现出来，而不是沉浸在找好的故事上。有些故事拍摄的人也比较多了，比如今天我看到的一个片子叫《法图麦》，大概讲的是一个回族女孩未婚先孕、不得不结婚的故事。这种故事在影像中找，或者小说中找，其实有蛮多的。但仅仅把它拍摄出来，不能够让大家有很深刻的体验的话，大家看完当下会有共鸣，但它的持久性是不够的。因为它是为了设计而去设计的一个影像，而不是作者通过自己的生命体验获得这场经历，然后把这样的生命经历共享到更多人。只有人和人之间这样的精神传递，才更加让人难忘。

**Q：这一年我们都知道，中国电影行业发生了很多变化，有的人越来越冷静，有的人觉得手机拍摄可能带来一些转变。您对当下的中国电影市场有什么看法？FIRST 能在其中发挥什么作用？**

我觉得这是一个很好的时代。我认为人人都可以创作，只要你拿起手机，把你的视角记录下来，就很有价值。

这是一个流量退潮的时代，流量在这过程中，明星也好流量也好，已经失效了。真正应该浮出水面的，我认为是好的内容。

FIRST 虽然主打的是青年创作者的第一步作品，但是我认为它在这过程中能够去挖掘和培养更多的影像创作者，甚至影响到那些还在上高中、初中的群体，让他们也开始去创作。我认为这件事情对中国电影有很大的影响。

**Q：有人说 FIRST 不仅有艺术欣赏的价值，还有很浓重的社交属性，这方面您有什么收获吗？**

确实给到了我很多社交的机会，我认识到了更多的导演，也和更多优秀的创作者见了面。但在这过程中，更重要的是你带什么样的目的来到电影节。如果你来电影节没有一个明确的目的，可能你在这里的社交不会有你想得到的东西。

所以电影也需要一个平台，把所有的创作者连接起来。我还是认为电影节在国内这样的市场，有非常重要的意义。

**Q：您刚才说想在这次 FIRST 上寻找可以组织放映的影片，现在有选择了吗？**

纪录片我计划会带回成都的是《河以为家》，长片我计划带回的是《地下美人》，短片我会带回去的是《飞天大王》和《溺婴》。

**Q：在短片方面，能展开讲讲您的观感吗？**

我发现这次有很多导演并不是把短片当作毕业作品来拍，他们可能是在剧本有了相关的资金之后，有充足的资金开始拍摄。反而这样的短片，它更能够体现短片的价值——在一个 20 分钟的叙事中，去强逻辑地编排自己的剧本，并且去布置相关的景。

反而是速拍式的学生作品，我不觉得它能够在 FIRST 的短片单元中崭露头角。说实话，我感觉短片竞争的激烈程度比长片还要激烈。

在这过程中也看到了很多短片作品邀请了一些已经出名的演员来出演，比如我看到了韩三明、虚害膨，这些都是以演长片为主的演员，但他们依然愿意去帮助青年创作者去创作短片。因为他们的加入，让这些短片变得更有质感，这是年轻演员可能达不到的一种状态。

**Q：最后一个问题。现在很多人说 FIRST 非常自嗨，近两年都有这样的言论。包括在 FIRST 反响特别好的一些电影，到了更大众的平台可能不会受到那么好的评价。比如去年在产业放映口碑特别好的那部《DB》，走向流媒体平台之后收到了 80% 的差评。您觉得 FIRST 算自嗨吗？或者说您对这个现象有什么更深的理解？**

我觉得这还是关于圈层的问题。大家觉得好的片子它确实有好的一面，但这个好得看是谁给它做的好评。来到 FIRST 看片的大多数人，据我了解到还是行业的创作者，以及关注这些青年创作独立影片的影迷。

所以我们不可否认《DB》这部片子它的口碑，但是当你流传到市场上之后，市场上你会面临到非电影行业、甚至是非专业影迷的评价。大家可能更关注的是叙事性、和自己经历的贴合性，以及普世的价值观。从电影鉴赏上来说，让影迷狂欢的作品大多数是这种抽象意义的作品。但是这样的片子你去把它推广到大众市场的时候，大众不一定能够接受它。

所以我觉得不一定要把 FIRST 作为一个标尺——FIRST 认证的不代表市场认证。不要把这两者强行关联。可能在经历过一些深度的市场调研之后，对某部作品能够获得更加贴切的评价和判断，而不是仅以 FIRST 的奖项也好、FIRST 的反应也好去评价市场。这是我的一点看法。
