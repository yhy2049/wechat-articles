📋 文章索引

📄 单篇文章

GET https://yhy2049.github.io/wechat-articles/articles/2026/2026-09-07-xxx.md

直接获取 Markdown 原文

🤖 调用示例

JavaScript / Node.js

const response = await fetch('https://yhy2049.github.io/wechat-articles/api/index.json');
const data = await response.json();
console.log('文章总数:', data.total);

// 获取某篇文章内容
const article = await fetch(data.articles[0].url);
const markdown = await article.text();

Python

import requests

# 获取文章索引
r = requests.get('https://yhy2049.github.io/wechat-articles/api/index.json')
data = r.json()

# 获取某篇文章
r = requests.get(data['articles'][0]['url'])
markdown = r.text
