# 24帧合作资源库·总览

> 一句话：这不是一份"合作名单"，而是一份把 2022–2026 年 302 篇公众号推文拆成"场地—人物—机构—案例"的可检索资源底稿。所有数字都标了口径，所有不确定都留在 [[06_待核实清单]]。

## 先看结论

1. **场地已经从"打游击"变成"固定影院网络"**：2022 年在 HOME+空间、上海贵酒体验中心、暗房里、源动力潮盛华等非标空间流动；2024 年下半年起保利万和（招商花园城店）成为绝对主力，2025–2026 年形成"保利万和招商花园城 + 苏宁影城苏宁广场 + 保利万和三利爱琴海 + 寰映大魔方 + 百丽宫太古里"的影院矩阵，非标空间保留给影展、沙龙和品牌活动。
2. **导演/主创资源不是"通讯录"，是三层关系**：核心层是多次合作、愿意再来/连线的主创（蔡杰、秦天、李泓翰、秦潇越、久美成列、金巴、楚布花羯、徐筱、陈语沙、仇晟、何力、张帆等）；稳定层是单次现场/连线但有作品与影展背书的导演；外围层是短片展和 FIRST 主动放映积累的青年导演网络。
3. **机构合作里最值钱的是"连续四年 FIRST + 戛纳一日/戛纳短片系列 + 方所/时代美术馆"**：FIRST 是片源与荣誉体系，戛纳/威尼斯/柏林一日是国际短片策展能力，方所和时代美术馆是城市文化空间的品牌背书。
4. **24帧已经不只是一家放映组织**：2025 年底更名 24FRAMES PROJECT，2026 年同时做短片自制（《夜游》《弄死一条过》）和院线长片联合制片（《浮生若丽》），资源结构从"借场地、请导演"扩展到"联合制片、剧组招募、城市文旅"。
5. **这份资料有边界**：公众号推文是"活动传播记录"，不等于实际场次；场地/嘉宾的写法经常不统一；部分活动只写"三环内/报名后通知"。对外使用前，先过一遍 [[06_待核实清单]]。

## 一、资料怎么来的

- **主数据源**：`05_档案/公众号存档` 2022–2026 年共 **302 篇**文章（2022 年 48 篇、2023 年 63 篇、2024 年 72 篇、2025 年 66 篇、2026 年 53 篇）。
- **提取方式**：逐篇阅读，按"活动类型 / 场地 / 地址 / 到场人物 / 合作方 / 影片或活动 IP / 备注"七列结构化；纯影评、随笔、声明、招募无具体活动信息的标为"非活动"。
- **口径**：一条推文 = 一条活动记录。系列放映（如哈利波特 8 部、北野武 8 部）按推文计 1 条，不按实际场次拆分；同一活动多篇推文（预告、报名、回顾）分别保留，因为不同篇可能补充不同资源信息。
- **规模校验**：另用 `05_档案/放映数据/24帧放映数据.xlsx` 做交叉校验——2022.05–2026.05 累计 **278 场、14,319 人次、220 部影片**；2025 年 **48 场放映 + 11 场路演 + 3 场远程连线**（年会推文口径）。两套数据不是同一个口径，不要混用。
- **既有资料**：`~/Downloads/24帧资源梳理(1).docx` 里的社群规模、部分导演履历、部分场地地址，已在相关分册标注"既有资料口径"；与公众号存档冲突的地方，以存档原文为准，并列入待核实。

## 七、怎么用这份资料

- **对外提案/招商**：先看 [[01_场地资源]] 和 [[03_合作机构与品牌]] 找"可复用合作方"，用 [[04_活动案例库]] 找同类型案例，用 [[05_数据统计]] 给规模，用 [[06_待核实清单]] 核风险。
- **邀约导演**：在 [[02_导演与嘉宾]] 按"剧情长片/纪录片/短片/演员/制片人"筛，先看"参与形式"是现场、连线还是 VCR，不要把连线写成到场。
- **场地谈判**：在 [[01_场地资源]] 看历史频次、合作性质（场地/联合主办/赞助/免费）、地址和厅号；保利万和系注意区分招商花园城、奥园广场、三利爱琴海三家店。
- **不要直接用**：匿名场地（三环内/东三环/高升桥/川大望江）、"以实际到场为准"的嘉宾、正文为空或图片未转文字的场次、既有资料与存档冲突的履历。以上都在 [[06_待核实清单]]。
